## 这份图是脚本生成的

原理图不是在 KiCad 里手画的，而是由 `gen/design.py` 生成。每个引脚引出一小段线，接一个网络标号，
同名的标号就是连在一起，所以图上看不到长连线。

要改电路：改 `gen/design.py`，然后运行

```bash
gen/build.sh
```

它会重新生成全部图纸，用 KiCad 导出网表并和脚本里写的连接逐脚比对，再跑 ERC、导出 PDF；
然后生成封装库和 PCB，跑 DRC 和"PCB 与原理图是否一致"的检查。
直接在 KiCad 里改图，下次生成时会被覆盖。

**PCB 目前也是脚本整板生成的**：`gen/place.py` 是每个元件的位置，`gen/board.py` 生成摆好的板子，
`gen/route.py`（核心是 `gen/route_core.c`）自动布线并铺铜。每次运行都会重摆、重布。
等布线接近完成、需要手工收尾时，就不能再整板重新生成了。

## 检查结果

- 网表比对：833 个引脚全部与脚本里写的连接一致。
- KiCad ERC：0 个错误，1 个警告（功放散热焊盘接地，符号库里这个脚的类型是"未指定"，可以忽略）。
- PCB 与原理图一致性：213 个封装、全部焊盘的网络都与原理图一致。
- KiCad DRC：元件之间没有重叠，没有超出板边；已布的线没有间距、短路、孔距类的违规。
  有 1 个 0.14 mm 线头的警告（清理它的代码已改，下次运行生效）。
  剩下 69 个"未连接"，分布在 66 个网络上，就是还没布通的那些连接。

这些只说明"图和脚本一致、没有悬空或短接、摆放不打架"，**不代表电路经过了实物验证**。

## PCB 布线现状（六层）

叠层和规则见规范。六层的用法：第 1、6 层放元件和短线，第 2、5 层整层地，第 3 层走信号，第 4 层铺 3.3 V。

自动布线是自己写的网格搜索程序（带拆线重布），不是成熟的布线器。同一份摆放跑了两种设置：

| 设置 | 布通 | DRC | 3.3 V 铺铜 |
|---|---|---|---|
| 第 4 层只放 3.3 V（规范 STK-6 的默认做法，**仓库里是这一版**） | 514 / 580 | 1 个线头警告 | 基本完整，3 处没连上 |
| 第 4 层也走信号 | 527 / 580 | 0 条违规 | 被信号线切断，16 处没连上，不符合 STK-6 |

对比四层版（484 / 579），加层带来的提升有限。原因查过了，不在层数：

- 没连上的 66 处里，只有 3 处是被焊盘和固定铜彻底堵死的，其余只是被别的走线挡住。
- 没连上的焊盘几乎全在正面，集中在两个模组的焊盘列和顶部排线座一带。那里正反两面合计每平方厘米 50 ~ 80 个焊盘，
  落过孔的位置不够；而板子下方只有约 15 个。第 3 层和板子下方三分之一都还很空。
- 所以要靠**重新摆放正面的小元件**（摄像头切换芯片、扩展芯片等现在正好压在 ESP32 焊盘列的背面）来解决，
  调布线程序的作用有限：先布短连接、只拆挡路的一段、保留最好结果，这几项加起来只从 501 提到 514。

没布通的清单在 `build/routing.json` 和 `build/open.json`（后者带位置，以及是否被彻底堵死）。

### 已经按规范做了的

| 规范条目 | 做法 | 量出来的结果 |
|---|---|---|
| RF-1 / RF-2 / RF-6 / RF-7 | 天线线只走背面、不打孔，线宽 0.34 mm，从模组脚到天线座是一条直线加一个 45° 小拐 | 走线 6.5 mm（不含焊盘） |
| RF-3 / RF-4 | 第 5 层只在天线座信号焊盘下开窗，离天线座的地焊盘留 0.2 mm；窗下方的第 4 层是地、禁止走线 | 开窗 1.65 × 1.50 mm，下方的地 3.65 × 3.50 mm |
| RF-5 / RF-9 | 线两侧铺地（间隙 0.2 mm）并打地孔；背面其它信号和过孔离线 1 mm 以上 | 线旁 11 个地孔；最近的别的过孔离线 1.05 mm |
| RF-8 | 匹配元件摆成一条直线：并联电容的信号焊盘压在线上，串联电阻串在线里 | — |
| DEC-2 / DEC-4 | ESP32：过孔 → 22 µF → 100 nF → 3V3 脚；其它 3.3 V 引脚旁边有电容的，先连到电容，不单独打孔 | 6 个引脚按这种方式连 |
| PWR-1（部分） | Air780E 供电是背面一整块铜皮，连着电源开关、220 µF 和模组供电脚 | C19 正极到供电脚 1.76 mm（见规范"待定问题"） |
| USB-2（部分） | ESP32 到切换芯片的长段在第 3 层并排走，0.19 / 0.15 mm | 四段长度差 1.3 / 0 / 0.9 / 2.8 mm，**不满足 USB-3** |

以上走线在 PCB 文件里是**锁定**的（KiCad 里显示小锁），自动布线不会动它们。

### 用 Freerouting 接着布（在自己的电脑上）

`freerouting/zeebuddy-mainboard.dsn` 是给开源自动布线器 Freerouting 用的板子文件：元件已摆好；
天线线、USB、ESP32 去耦这几段关键走线已经画好并且**锁定**（Freerouting 不会动它们）；其余的线留给它布。
两层地和 3.3 V 那一层标成了电源层，Freerouting 不会在上面走信号线，只用第 1、3、6 层。

1. **装 Freerouting。** 打开 https://github.com/freerouting/freerouting/releases ，在最新版本下面：
   - 下载自己系统（Windows / macOS / Linux）的安装包，安装后打开；
   - 或者下载 `freerouting-版本号.jar`，先装 Java（https://adoptium.net/temurin/releases/ ，选 JRE 25），
     然后在终端 / 命令提示符里运行 `java -jar freerouting-版本号.jar`。
     macOS 用 jar 时要从"终端"启动，从访达双击不行。
2. **拿到板子文件。** 从仓库下载 `hardware/esp32-s3-board/kicad/freerouting/zeebuddy-mainboard.dsn`。
3. **打开。** Freerouting 菜单 `File → Open...`，选这个 `.dsn`。能看到板子外形、元件焊盘和已经锁定的几段线。
4. **开始自动布线。** 点工具栏上的魔术棒图标（Autorouter）。它会一轮一轮地布，窗口下方显示还剩多少条没连上
   （unrouted）。这块板子比较挤，可能要十几分钟到一两个小时。
5. **等它停。** 未连接数降到 0、或者连续很多轮不再减少，就可以停了（再点一下鼠标会中断自动布线）。
6. **保存结果。** 菜单 `File → Save as...`，存成 `zeebuddy-mainboard.ses`（文件名以 `.ses` 结尾）。
7. **交回来。** 把这个 `.ses` 放进仓库的 `hardware/esp32-s3-board/kicad/freerouting/` 目录（或者直接发给我），
   然后运行下面的命令导入、铺铜：

   ```bash
   /usr/bin/python3.12 gen/freeroute.py . --ses freerouting/zeebuddy-mainboard.ses
   ```

   之后跑一遍 DRC，看还剩什么没连上、有没有违规。

注意：

- Freerouting **不会**把 USB 当差分对来走，所以 USB 是先在这边画好再锁定的，不要在 Freerouting 里解锁它们。
- 如果有 KiCad，也可以不用上面的脚本：在 PCB 编辑器里 `文件 → 导入 → Specctra Session` 导入 `.ses`。
  但那样导入的是仓库里现有的板子，要先确认它和 `.dsn` 是同一版摆放。
- `.dsn` 由 `gen/freeroute.py` 生成；元件位置变了要重新生成，旧的 `.ses` 就不能用了。
- 不想点界面也可以用一条命令（第 3 ~ 6 步合成一步，布完自动保存）：

  ```bash
  java -jar freerouting-版本号.jar -de zeebuddy-mainboard.dsn -do zeebuddy-mainboard.ses -mp 100
  ```

## PCB 摆放

- 外形和四个螺丝孔取自参考主板 M03 的 STEP 模型：64 × 34 mm（参考板是 0.8 mm 四层；本板是 1.6 mm 六层）。
  右上角的螺丝孔离板边只有 1.2 mm，放不下铜环，做成了不带铜的孔；另外三个孔的铜环接地。
- **背面是"高"的一面**：ESP32-S3 模组（高 3.2 mm）、Air780E（2.3 mm）、屏 / 触摸 / 后摄的排线座、电池和喇叭焊盘、充电芯片；
  下边缘从背面看由左到右是 **TF 卡座、Type-C、4G 天线座、SIM 卡座**，三个对外的口在同一面同一条边。
- **正面是"低"的一面**：前摄排线座、两个按键排线座、麦克风、下载焊盘，以及绝大部分小元件。
  充电芯片的外围、Air780E 的大电容和电源开关、ESP32 的去耦电容、天线匹配放在背面，紧挨着对应的引脚。
- 与参考主板位置相同的：Type-C、SIM 卡座、电池焊盘、喇叭焊盘、麦克风、按键排线 A。其它位置是我定的。
- 为了把 TF 卡座放到背面，ESP32 模组顶到了上边缘，Air780E 横过来放。代价是 Air780E 四周的间距只剩
  1.3 ~ 2.2 mm（到排线座 1.3、到 SIM 卡座 1.6、到 Type-C 1.9、到 ESP32 模组 2.2），合宙建议是 3 mm。
- 图纸坐标：板子左上角在 KiCad 页面的 (100, 60) mm 处。

**占位的封装**（型号定了要换）：三种排线座（按常见的 0.5 mm 翻盖座估的尺寸）、SIM 卡座（GCT SIM8060）、
TF 卡座（Molex 104031-0811）、Type-C（HRO TYPE-C-31-M-12）、两个轻触开关、IO 扩展芯片（按 TI 的 QFN-24 封装）。

## 可以替换的料

| 图上的型号 | 可替换 | 说明 |
|---|---|---|
| SY6970QCC | BQ25895RTWR | 24 个脚相同，贵约 6 元；TI 的数据手册用 2.2 µH 电感 |
| XL9555QF24 | TCA9555RTWR | 脚位相同；TCA9555 没有内部上拉 |
| SY8089AAAC | TLV62569DBV | 脚位和反馈电压相同 |

没有采用 NS4168 功放：它的逻辑高电平要求 0.7 × 供电电压，功放用电池电压供电时 3.3 V 的信号不够高；
改用 3.3 V 给它供电又会损失输出功率。
