# 屏打样要求：16 位并口 RGB 版本（NV3049F，给屏厂）

日期：2026-11-14。**取代之前的 8 位串行 RGB 版本要求**：主控换成 ESP32-S31 以后，引脚够接 16 位并口了。
另一家屏也用同样的接口和同一个 40 脚定义，主板只放一个座子。

## 1. 一句话要求

2.8 英寸、480 × 640、驱动芯片 NV3049F 的**触摸屏总成**（屏 + 电容触摸 + 盖板 + 排线），图像走 **16 位并口 RGB（RGB565）**，
初始化命令走三线 SPI，排线末端用亚奇板对板公座，脚位按第 3 节的 40 脚定义。先做 3 ~ 5 片样品。

## 2. 接口要求

| 项目 | 要求 |
|---|---|
| 尺寸、分辨率 | 2.8 英寸，480 × 640，竖屏 |
| 图像接口 | **16 位并口 RGB**：D0 ~ D15（RGB565）+ DOTCLK、DE、HSYNC、VSYNC |
| 命令接口 | 三线 SPI（CS、SCL、SDA），9 位一帧，只在开机发初始化命令，只写不读 |
| **IO 电平** | **必须是 3.3 V**。我们的主控是 3.3 V，16 根数据线没法加电平转换 |
| 供电 | 主板只给一路 3.3 V |
| 像素时钟 | 计划约 **21 ~ 25 MHz，每秒 60 帧** |
| 复位 | RST，低有效。主板上有下拉，上电后屏先处于复位 |
| 背光 | **灯必须串联**，电流 20 mA，4 ~ 6 颗串联都可以（约 12 ~ 20 V）。主板的背光是升压恒流电路，**并联的灯用不了** |
| 触摸 | 电容触摸，和屏贴成一体，信号并进同一条排线（第 3 节第 37 ~ 40 脚），见第 3.1 节 |

数据线的颜色对应（RGB565）：**D15 ~ D11 = 红 R4 ~ R0，D10 ~ D5 = 绿 G5 ~ G0，D4 ~ D0 = 蓝 B4 ~ B0**。
NV3049F 的哪几根数据脚接 D0 ~ D15，请按它的 16 位模式在排线上排好。

**备选**：如果 NV3049F 做不了 16 位并口，就按 8 位串行 RGB 做（每个像素 3 个时钟），用同一个 40 脚定义，
8 根数据线接第 20 ~ 27 脚（D0 ~ D7），第 28 ~ 35 脚不接。请在第 5 节第 1 条答复。

**排线末端：亚奇品牌板对板公座**，主板上贴配套母座，主板这边在背面的上边缘。

- **型号已定（2026-11-14）：亚奇 OCN OK-128 系列，0.35 mm 间距，配合高度 0.6 mm，40 个信号脚 + 两端 2 个电源脚。** 排线上贴**公座 OK-128GM040/2-35**，主板贴**母座 OK-128GF040/2-35**（"040"是脚数，完整料号以亚奇报价单为准）。规格书已随本文件发给你们。
- 两端的 2 个电源脚（端头金属件）**接地**，主板这边也接地。
- 请给我们一张"母座脚号 → 信号"的对照表。**公座和母座脚号是镜像的，对照表一律按主板母座的脚号写**，排线图上标出 1 脚位置。
- 排线在公座背面要贴补强板，方便压紧；整机里座子上方会压泡棉防跌落松脱。
- 你们觉得别的顺序更好出线，可以提出来，我们主板还没定稿。

## 3.1 触摸

| 项目 | 要求 |
|---|---|
| 类型 | 电容触摸，单点即可，支持两点更好 |
| 触摸芯片 | 建议 CST836U（I²C）；用别的芯片请告诉我们型号 |
| 结构 | 触摸盖板和屏贴成一体，请说明是全贴合还是框贴 |
| 接口 | I²C，主板上有 3.3 V 上拉；中断和复位低有效 |
| 供电 | 用排线上的 3.3 V（第 6、7 脚）。芯片如果只能用 2.8 V，请在排线上自带稳压，或者告诉我们 |
| 排线 | 触摸的小排线接到屏的排线上，从同一个公座出来 |

## 4. 屏厂这边要做的

1. 芯片接口配置成"16 位并口 RGB + 三线 SPI"（IM 脚在排线或玻璃上接好）。
2. 给出这个模式下的**完整初始化代码**、推荐的时序参数（前后沿、同步宽度、极性）。
3. 排线按第 3 节出线，提供排线图：长度、出线位置、弯折位置、公座位置和朝向、第 1 脚位置。
4. 触摸、盖板一起贴好，做成总成。

## 6. 样品到了我们怎么验

1. 用你们给的初始化代码点亮，彩条、灰度渐变颜色正确。
2. 像素时钟 21 ~ 25 MHz 下长时间显示稳定，不花屏、不漂移。
3. 实测刷新率，慢动作录像看不闪。
4. 同时开摄像头取景，画面稳定。
5. 触摸：读出触摸芯片 ID，单点、两点坐标正确，四个角和边缘都能点到。
