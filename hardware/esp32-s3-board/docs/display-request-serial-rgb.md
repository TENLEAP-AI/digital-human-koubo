# 屏打样要求：8 位串行 RGB 版本（NV3049F，给屏厂）

日期：2026-11-12，2026-11-13 加上触摸。我们的主板已经按这个接口画好，屏按下面做出来就能直接用。

## 1. 一句话要求

2.8 英寸、480 × 640、驱动芯片 NV3049F 的屏，接口做成 **8 位串行 RGB + 三线 SPI**，排线按第 3 节的 22 脚定义出；**带电容触摸**，触摸排线按第 3.1 节的 6 脚定义出。
先做 3 ~ 5 片样品，屏和触摸一起打样。

## 2. 接口要求

| 项目 | 要求 |
|---|---|
| 图像接口 | **8 位串行 RGB**：只用 8 根数据线 D7 ~ D0，每个像素分 3 个时钟送（红、绿、蓝各一个字节），加 DOTCLK、HSYNC、VSYNC、DE |
| 命令接口 | 三线 SPI（CS、SCL、SDA），9 位一帧，只用来发初始化命令。我们只写不读 |
| 逻辑电平 | 3.3 V |
| 供电 | 主板只给一路 3.3 V |
| 复位 | RST，低有效 |
| 背光 | **灯必须串联**，电流 20 mA。主板按 6 颗串联、约 18 V 做的，4 ~ 6 颗串联都可以。主板的背光是升压恒流电路，**并联的灯用不了** |

**请注意：我们要的不是 16 位或 18 位的并口 RGB。** 并口要 16 根以上的数据线，我们的主控引脚不够，只能给 8 根。

| 4 | SCL | 主板 → 屏 | SPI 时钟 |
| 5 | NC | — | 不接 |
| 6 | VCI | 电源 | 3.3 V |
| 7 | D7 | 主板 → 屏 | 数据最高位 |
| 8 | D6 | 主板 → 屏 | |
| 9 | D5 | 主板 → 屏 | |
| 10 | D4 | 主板 → 屏 | |
| 11 | D3 | 主板 → 屏 | |
| 12 | D2 | 主板 → 屏 | |
| 13 | D1 | 主板 → 屏 | |
| 14 | D0 | 主板 → 屏 | 数据最低位。8 根数据线主板全接 |
| 15 | CS | 主板 → 屏 | SPI 片选 |
| 16 | DOTCLK | 主板 → 屏 | 像素时钟 |
| 17 | HSYNC | 主板 → 屏 | 行同步 |

| 19 | VSYNC | 主板 → 屏 | 场同步 |

主板上的接口在主板背面的上边缘，用板对板公母座（见下面）。

**排线末端的做法：用亚奇品牌的板对板（BTB）公母座。**排线末端焊**公座**，主板上贴配套的**母座**。

- 请推荐亚奇的具体系列，给出**公座和母座的完整型号**（两者必须配套）、间距（常见 0.4 mm）、配合高度。配合高度希望 ≤1.0 mm，以结构最终确认为准。
- 上面的脚位表是**信号的顺序**。换成公母座后，请按所选型号的脚数重新排一张"母座脚号 → 信号"的对照表给我们：
  脚数比信号多的，多出的脚接地；公座和母座的脚号是镜像的，**对照表一律按主板上母座的脚号写**，避免两边对反。
- **触摸能并进同一个公母座的话，我们倾向并进**：触摸的小排线接到屏的排线上，屏和触摸从一个公座出来（比如 30 脚左右）。
  做不到就触摸单独一对小公母座。请告诉我们哪种可行。
- 排线上公座的位置、方向和背面的补强板，随排线图一起给。

## 3.1 触摸（一起打样）

屏上要带**电容触摸**。触摸优先并进屏的公母座（见上面）；并不进的话单独出一条排线，配一对小公母座。下表是触摸的 6 个信号。

| 项目 | 要求 |
|---|---|
| 类型 | 电容触摸，单点即可，支持两点更好 |
| 触摸芯片 | 建议 CST836U（I²C）；用别的芯片请告诉我们型号 |
| 结构 | 触摸盖板和屏贴成一体，请说明是全贴合还是框贴 |
| 接口 | I²C，主板上有 3.3 V 上拉；中断和复位低有效 |
| 供电 | 主板给 3.3 V。芯片如果只能用 2.8 V，请在触摸排线上自带稳压，或者告诉我们 |
| 排线 | 并进屏的公母座，或单独一对小公母座；从屏的哪边出、长度多少，请配合屏的排线一起给图 |

触摸的信号（并进屏的公母座时，按这个顺序排在屏的信号后面）：

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | TP-INT | 触摸 → 主板 | 中断，低有效 |
| 2 | TP-RST | 主板 → 触摸 | 复位，低有效 |
| 3 | TP-SCL | 主板 → 触摸 | I²C 时钟 |
| 4 | TP-SDA | 双向 | I²C 数据 |
| 5 | GND | | 地 |
| 6 | TP-VDD | 电源 | 3.3 V |

## 4. 屏厂这边要做的

1. **芯片的接口配置脚**（IM[3:0]）在排线或玻璃上接成"RGB + SPI"模式。
2. **把芯片设成 8 位串行 RGB 模式**，并给出这个模式下的完整初始化代码。
3. 排线按第 3 节的脚位出线。
4. 提供排线图：长度、出线位置、弯折位置、金手指朝哪一面、第 1 脚在哪边。屏和触摸两条排线都要。
5. 触摸和屏贴合，触摸排线按第 3.1 节出线，给出触摸芯片的驱动代码或寄存器说明。

## 5. 打样前请书面答复

| # | 问题 | 屏厂答复 |

第 1 和第 3 条最要紧：第 1 条不成立，这个方案就做不了；第 3 条决定画面流不流畅、闪不闪。

## 6. 样品到了我们怎么验

先不上主板，用开发板点亮：确认初始化代码能用、60 MHz 左右画面稳定不漂移、每秒 50 帧以上不闪、颜色和渐变正常。确认之后再定排线、投主板。

触摸：用开发板的 I²C 读出触摸芯片的 ID，单点、两点触摸坐标正确，四个角和边缘都能点到。
