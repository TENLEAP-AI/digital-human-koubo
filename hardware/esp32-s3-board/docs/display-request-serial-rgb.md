# 屏的改法说明：8 位串行 RGB 版本（给屏厂）

日期：2026-11-12。我们的主板已经按这个接口画好，屏按下面做出来就能直接用。

## 1. 一句话要求

2.8 英寸、480 × 640、驱动芯片 NV3049 系列的屏，接口做成 **8 位串行 RGB + 三线 SPI**，排线按第 3 节的 22 脚定义出。

## 2. 接口要求

| 项目 | 要求 |
|---|---|
| 图像接口 | **8 位串行 RGB**：只用 8 根数据线 D7 ~ D0，每个像素分 3 个时钟送（红、绿、蓝各一个字节），加 DOTCLK、HSYNC、VSYNC、DE |
| 命令接口 | 三线 SPI（CS、SCL、SDA），9 位一帧，只用来发初始化命令。我们只写不读 |
| 逻辑电平 | 3.3 V |
| 供电 | 主板只给一路 3.3 V |
| 复位 | RST，低有效 |
| 背光 | 串联灯串。主板现在按 6 颗串联、18 V、20 mA 做的；不一样请告诉我们 |

**请注意：我们要的不是 16 位或 18 位的并口 RGB。** 并口要 16 根以上的数据线，我们的主控引脚不够，只能给 8 根。

## 3. 排线脚位（22 脚，0.5 mm 间距）

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | LEDA | 电源 | 背光正极 |
| 2 | LEDK | 电源 | 背光负极 |
| 3 | SDA | 主板 → 屏 | SPI 数据 |
| 4 | SCL | 主板 → 屏 | SPI 时钟 |
| 5 | NC | — | 不接 |
| 6 | VCI | 电源 | 3.3 V |
| 7 | D7 | 主板 → 屏 | 数据最高位 |
| 8 | D6 | 主板 → 屏 | |
| 9 | D5 | 主板 → 屏 | |
| 10 | D4 | 主板 → 屏 | |
| 11 | D3 | 主板 → 屏 | |
| 12 | D2 | 主板 → 屏 | 首版主板上接地（见第 5 节） |
| 13 | D1 | 主板 → 屏 | 首版主板上接地 |
| 14 | D0 | 主板 → 屏 | 首版主板上接地 |
| 15 | CS | 主板 → 屏 | SPI 片选 |
| 16 | DOTCLK | 主板 → 屏 | 像素时钟 |
| 17 | HSYNC | 主板 → 屏 | 行同步 |
| 18 | DE | 主板 → 屏 | 数据有效 |
| 19 | VSYNC | 主板 → 屏 | 场同步 |
| 20 | RST | 主板 → 屏 | 复位，低有效 |
| 21 | GND | 电源 | 地 |
| 22 | GND | 电源 | 地 |

主板上的排线座：22 脚、0.5 mm 间距、翻盖式，在主板背面的上边缘。上接还是下接还没定，可以配合屏厂排线的金手指朝向来选。

## 4. 屏厂这边要做的

1. **芯片的接口配置脚**（NV3049 的 IM[3:0]）在排线或玻璃上接成"RGB + SPI"模式。
2. **把芯片设成 8 位串行 RGB 模式**，并给出这个模式下的完整初始化代码。
3. 排线按第 3 节的脚位出线。
4. 提供排线图：长度、出线位置、弯折位置、金手指朝哪一面、第 1 脚在哪边。

## 5. 请屏厂答复

| # | 问题 | 屏厂答复 |
|---|---|---|
| 1 | **你们用的 NV3049 支不支持 8 位串行 RGB？** 我们查到的 NV3049 手册（2014 年版）只写了 16 / 18 / 24 位并口和 MIPI，没写串行模式；但市面上有 NV3049F 的 8 位串行 RGB 屏。请确认芯片的具体型号（NV3049 还是 NV3049F）和是否支持 | |
| 2 | 串行模式下 3 个字节的颜色顺序（红绿蓝还是蓝绿红）；HSYNC、VSYNC、DE 的极性；行、场消隐的要求 | |
| 3 | **DOTCLK 的范围，以及最低刷新率。** 我们的主控只能给 20 ~ 26 MHz。480 × 640 每个像素 3 个时钟，算下来是**每秒 17 ~ 22 帧**。这个帧率下显示是否正常、有没有闪烁 | |
| 4 | 首版我们只驱动 D7 ~ D3，D2 ~ D0 在主板上接地（每种颜色 32 级）。屏这边有没有问题 | |
| 5 | 只给一路 3.3 V 行不行；电流多大 | |
| 6 | 背光：几颗灯、串联还是并联、电流、电压 | |
| 7 | 第 19 脚 VSYNC 和我们主控的调试串口共用：上电后约 1 秒内这根线上有不相干的波形，此时屏处于复位。屏能否承受 | |
| 8 | 带不带触摸；带的话触摸芯片型号、I²C 地址、排线脚位 | |
| 9 | 开模费、起订量、交期；能不能先给 3 ~ 5 片样品 | |

第 1 和第 3 条最要紧：第 1 条不成立，这个方案就做不了；第 3 条不成立，画面会闪。

## 6. 拿到样品后我们怎么验

先不上主板，用开发板点亮：确认初始化代码能用、20 MHz 下画面稳定不漂移、只接 5 根数据线时颜色可以接受。确认之后再定排线、投主板。
