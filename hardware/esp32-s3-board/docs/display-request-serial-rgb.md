# 屏打样要求：8 位串行 RGB 版本（NV3049F，给屏厂）

日期：2026-11-12，2026-11-13 加上触摸。我们的主板已经按这个接口画好，屏按下面做出来就能直接用。

## 1. 一句话要求

2.8 英寸、480 × 640、驱动芯片 NV3049F 的屏，接口做成 **8 位串行 RGB + 三线 SPI**，排线按第 3 节的 22 脚定义出；**带电容触摸**，触摸排线按第 3.1 节的 6 脚定义出。
先做 3 ~ 5 片样品，屏和触摸一起打样。

## 2. 接口要求

| 项目 | 要求 |
|---|---|
| 图像接口 | **8 位串行 RGB**：只用 8 根数据线 D7 ~ D0，每个像素分 3 个时钟送（红、绿、蓝各一个字节），加 DOTCLK、HSYNC、VSYNC、DE |
| 命令接口 | 三线 SPI（CS、SCL、SDA），9 位一帧，只用来发初始化命令。我们只写不读 |
| 逻辑电平 | 3.3 V |
| 供电 | 主板只给一路 3.3 V |
| 复位 | RST，低有效 |
| 背光 | **灯必须串联**，电流 20 mA。主板按 6 颗串联、约 18 V 做的，4 ~ 6 颗串联都可以。主板的背光是升压恒流电路，**并联的灯用不了** |

**请注意：我们要的不是 16 位或 18 位的并口 RGB。** 并口要 16 根以上的数据线，我们的主控引脚不够，只能给 8 根。

## 3. 排线脚位（22 脚，0.5 mm 间距）

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | LEDA | 电源 | 背光正极 |
| 2 | LEDK | 电源 | 背光负极 |
| 3 | SDA | 主板 → 屏 | SPI 数据 |
| 4 | SCL | 主板 → 屏 | SPI 时钟 |
| 5 | NC | — | 不接 |
| 6 | VCI | 电源 | 3.3 V |
| 7 | D7 | 主板 → 屏 | 数据最高位 |
| 8 | D6 | 主板 → 屏 | |
| 9 | D5 | 主板 → 屏 | |
| 10 | D4 | 主板 → 屏 | |
| 11 | D3 | 主板 → 屏 | |
| 12 | D2 | 主板 → 屏 | 首版主板上接地（见第 5 节） |
| 13 | D1 | 主板 → 屏 | 首版主板上接地 |
| 14 | D0 | 主板 → 屏 | 首版主板上接地 |
| 15 | CS | 主板 → 屏 | SPI 片选 |
| 16 | DOTCLK | 主板 → 屏 | 像素时钟 |
| 17 | HSYNC | 主板 → 屏 | 行同步 |
| 18 | DE | 主板 → 屏 | 数据有效 |
| 19 | VSYNC | 主板 → 屏 | 场同步 |
| 20 | RST | 主板 → 屏 | 复位，低有效 |
| 21 | GND | 电源 | 地 |
| 22 | GND | 电源 | 地 |

主板上的排线座：22 脚、0.5 mm 间距、翻盖式，在主板背面的上边缘。上接还是下接还没定，可以配合屏厂排线的金手指朝向来选。

**排线末端的做法：金手指插座子，不用板对板公母座。**两条排线（屏 22 脚、触摸 6 脚）末端都做成 0.5 mm 间距的**金手指，背面加补强板**，
直接插进主板上的翻盖式 FPC 座，**不要焊板对板（BTB）公母座**。金手指处的总厚度按 0.3 mm 做（常用 0.5 mm 翻盖座的要求），
金手指朝上还是朝下请你们按出线方便定，告诉我们，我们按它选上接或下接的座子。

## 3.1 触摸（一起打样）

屏上要带**电容触摸**，触摸单独出一条 **6 脚、0.5 mm** 的排线，不并进上面的 22 脚。主板上有一个专门的 6 脚触摸排线座。

| 项目 | 要求 |
|---|---|
| 类型 | 电容触摸，单点即可，支持两点更好 |
| 触摸芯片 | 建议 CST836U（I²C）；用别的芯片请告诉我们型号 |
| 结构 | 触摸盖板和屏贴成一体，请说明是全贴合还是框贴 |
| 接口 | I²C，主板上有 3.3 V 上拉；中断和复位低有效 |
| 供电 | 主板给 3.3 V。芯片如果只能用 2.8 V，请在触摸排线上自带稳压，或者告诉我们 |
| 排线 | 6 脚、0.5 mm，从屏的哪边出、长度多少，请配合屏的排线一起给图 |

触摸排线脚位：

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | TP-INT | 触摸 → 主板 | 中断，低有效 |
| 2 | TP-RST | 主板 → 触摸 | 复位，低有效 |
| 3 | TP-SCL | 主板 → 触摸 | I²C 时钟 |
| 4 | TP-SDA | 双向 | I²C 数据 |
| 5 | GND | | 地 |
| 6 | TP-VDD | 电源 | 3.3 V |

## 4. 屏厂这边要做的

1. **芯片的接口配置脚**（IM[3:0]）在排线或玻璃上接成"RGB + SPI"模式。
2. **把芯片设成 8 位串行 RGB 模式**，并给出这个模式下的完整初始化代码。
3. 排线按第 3 节的脚位出线。
4. 提供排线图：长度、出线位置、弯折位置、金手指朝哪一面、第 1 脚在哪边。屏和触摸两条排线都要。
5. 触摸和屏贴合，触摸排线按第 3.1 节出线，给出触摸芯片的驱动代码或寄存器说明。

## 5. 打样前请书面答复

| # | 问题 | 屏厂答复 |
|---|---|---|
| 1 | **请书面确认：芯片是 NV3049F，样品用 8 位串行 RGB**，也就是只用 8 根数据线、每个像素分 3 个时钟送。我们查到的 NV3049 手册（2014 年版）只写了 16 / 18 / 24 位并口和 MIPI，所以请把 NV3049F 规格书里讲串行 RGB 的那几页发给我们 | |
| 2 | 串行模式下 3 个字节的颜色顺序（红绿蓝还是蓝绿红）；HSYNC、VSYNC、DE 的极性；行、场消隐的要求 | |
| 3 | **DOTCLK 的范围，以及最低刷新率。** 我们的主控只能给 20 ~ 26 MHz。480 × 640 每个像素 3 个时钟，算下来是**每秒 17 ~ 22 帧**。这个帧率下显示是否正常、有没有闪烁 | |
| 4 | 我们查到 NV3049F 的屏是 RGB666（每种颜色 6 位）。**每个颜色字节的 8 位里，哪 6 位有效，是不是 D7 ~ D2？** 首版我们只驱动 D7 ~ D3，D2 ~ D0 在主板上接地（每种颜色 32 级），屏这边有没有问题 | |
| 5 | 只给一路 3.3 V 行不行；电流多大 | |
| 6 | 背光能不能按串联做；几颗灯、电压、电流 | |
| 7 | 第 19 脚 VSYNC 和我们主控的调试串口共用：上电后约 1 秒内这根线上有不相干的波形，此时屏处于复位。屏能否承受 | |
| 8 | 触摸：芯片型号、I²C 地址、能不能直接用 3.3 V 供电；中断是推挽还是开漏；驱动代码或寄存器说明 | |
| 9 | 排线图（屏和触摸两条）：长度、从模组哪边出线、弯折位置、金手指朝哪一面、第 1 脚在哪边 | |
| 10 | 打样费、开模费、起订量、交期 | |

第 1 和第 3 条最要紧：第 1 条不成立，这个方案就做不了；第 3 条不成立，画面会闪。

## 6. 样品到了我们怎么验

先不上主板，用开发板点亮：确认初始化代码能用、20 MHz 下画面稳定不漂移、只接 5 根数据线时颜色可以接受。确认之后再定排线、投主板。

触摸：用开发板的 I²C 读出触摸芯片的 ID，单点、两点触摸坐标正确，四个角和边缘都能点到。
