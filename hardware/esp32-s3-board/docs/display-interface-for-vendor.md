# 屏排线接口定义（给屏厂）

日期：2026-11-12。对应主板：Zeebuddy 主板 V1（`hardware/esp32-s3-board/kicad`）。

屏厂按这份定义做排线。**脚位顺序沿用 LB28BOE47 标准排线的顺序**，没有重排：这样标准品的排线只要金手指朝向对得上，
也能直接插在我们的板子上。

## 1. 我们怎么用这块屏

| 项目 | 内容 |
|---|---|
| 屏 | LB28BOE47，2.8 英寸，480 × 640，驱动芯片 NV3049F |
| 显示接口 | 8 位串行 RGB（每个像素 3 个时钟），加 HSYNC、VSYNC、DE、DOTCLK |
| 配置接口 | 三线 SPI（CS、SCL、SDA），只用来发初始化命令 |
| 逻辑电平 | 3.3 V |
| 主控 | ESP32-S3（8 MB 八线 PSRAM） |
| **首版只接 5 根数据线** | D7 ~ D3 接主控，D2 ~ D0 在主板上经 0 Ω 接地。每种颜色 32 级 |

## 2. 主板上的排线座

| 项目 | 内容 |
|---|---|
| 位号 | J8 |
| 规格 | 22 脚，0.5 mm 间距，翻盖式 |
| 位置 | 主板**背面**，上边缘。排线从上边缘插入 |
| 第 1 脚 | 距主板左边 10.95 mm（从正面看的坐标）；第 22 脚距左边 21.45 mm。**从背面看，第 1 脚在右边** |
| 上接还是下接 | **还没定**，要和屏厂、结构一起定（见第 6 节） |
| 座子型号 | 还没选。可以按屏厂排线的厚度和金手指来选 |

所有排线座在板上的位置见 [`../kicad/connector-positions.png`](../kicad/connector-positions.png)。

## 3. 脚位

方向一栏："出"是主板输出给屏，"电源"是主板供电。

| 脚 | 名称 | 方向 | 电平 | 主板这边 | 说明 |
|---|---|---|---|---|---|
| 1 | LEDA | 电源 | 最高约 27 V | 背光升压输出 | 背光正极。串联恒流驱动，见第 5 节 |
| 2 | LEDK | 电源 | 约 0.2 V | 电流采样电阻 5.1 Ω | 背光负极。恒流约 39 mA（可改电阻调整） |
| 3 | SDA | 出 | 3.3 V | I/O 扩展芯片 | SPI 数据。**只写不读**；速度很慢（每秒几千位） |
| 4 | SCL | 出 | 3.3 V | I/O 扩展芯片 | SPI 时钟 |
| 5 | NC | — | — | 不接 | |
| 6 | VCI | 电源 | 3.3 V | 3.3 V 经 0 Ω，旁边 1 µF + 100 nF | 屏的供电。主板只提供 3.3 V 这一路 |
| 7 | D7（G7） | 出 | 3.3 V | ESP32 GPIO42 | 数据最高位 |
| 8 | D6（G6） | 出 | 3.3 V | ESP32 GPIO41 | |
| 9 | D5（G5） | 出 | 3.3 V | ESP32 GPIO40 | |
| 10 | D4（G4） | 出 | 3.3 V | ESP32 GPIO39 | |
| 11 | D3（G3） | 出 | 3.3 V | ESP32 GPIO38 | |
| 12 | D2（G2） | — | 0 V | 经 0 Ω 接地 | 首版不驱动 |
| 13 | D1（G1） | — | 0 V | 经 0 Ω 接地 | 首版不驱动 |
| 14 | D0（G0） | — | 0 V | 经 0 Ω 接地 | 首版不驱动 |
| 15 | CS | 出 | 3.3 V | I/O 扩展芯片 | SPI 片选 |
| 16 | DOTCLK | 出 | 3.3 V | ESP32 GPIO47，串 33 Ω | 像素时钟。计划 20 ~ 26 MHz |
| 17 | HSYNC | 出 | 3.3 V | ESP32 GPIO44，串 100 Ω | 和主控的串口 0 接收脚共用 |
| 18 | DE | 出 | 3.3 V | ESP32 GPIO48 | |
| 19 | VSYNC | 出 | 3.3 V | ESP32 GPIO43，串 470 Ω | 和主控的串口 0 发送脚共用：上电后约 1 秒内这根线上有启动信息的波形，此时屏处于复位 |
| 20 | RST | 出 | 3.3 V | I/O 扩展芯片，主板有 4.7 kΩ 下拉 | 低有效。上电默认低，主控初始化完才释放 |
| 21 | GND | 电源 | 0 V | 地 | |
| 22 | GND | 电源 | 0 V | 地 | |

## 4. 请屏厂确认或提供

| # | 事项 | 屏厂答复 |
|---|---|---|
| 1 | 排线图：长度、宽度、出线位置、弯折位置、金手指朝哪一面、补强板、第 1 脚标记 | |
| 2 | NV3049F 在 **8 位串行 RGB、480 × 640** 下的完整初始化代码，以及三线 SPI 的格式（每帧几位、先发高位还是低位） | |
| 3 | 时序：DOTCLK 的最小、典型、最大值；每个像素 3 个时钟的颜色顺序；HSYNC、VSYNC、DE 的极性；行、场消隐 | |
| 4 | 最低刷新率。我们的主控只能做到 **20 ~ 25 帧 / 秒**（DOTCLK 20 ~ 26 MHz），这个帧率下能不能正常显示、有没有闪烁 | |
| 5 | 只接 D7 ~ D3、D2 ~ D0 接地时显示是否正常 | |
| 6 | 背光：几颗灯、串联还是并联、额定电流、正向电压 | |
| 7 | VCI 的电流；是否还需要别的电源（比如单独的 1.8 V 接口电源） | |
| 8 | 上电顺序的要求：VCI、RST、信号线各自的先后和间隔 | |
| 9 | 第 19 脚（VSYNC）在复位期间有波形，屏能否承受 | |
| 10 | 触摸：芯片型号、I²C 地址、排线脚位；触摸和屏是分开两条排线还是合成一条 | |

## 5. 背光

主板的背光电路是**串联恒流升压**：输出电压自动跟随灯串，最高约 27 V（过压保护点约 30 V），电流由一颗电阻定，
现在是约 39 mA，按"6 颗灯串联、约 9.6 V、40 mA"预设的，**这块屏的实际背光规格还没拿到**。

- 如果是串联灯串：告诉我们电流和电压，我们只改一颗电阻。
- 如果是并联的低压背光（比如 4 颗并联、约 3 V、80 mA）：这个电路带不了，要提前告诉我们改电路。

## 6. 触摸排线座（J9）

现在是按常见定义占位的，**没有依据，等屏厂给脚位**：

| 脚 | 我们的假设 | 主板这边 |
|---|---|---|
| 1 | VDD 3.3 V | 3.3 V |
| 2 | GND | 地 |
| 3 | SCL | I²C 时钟（和摄像头、扩展芯片、充电芯片共用一条总线） |
| 4 | SDA | I²C 数据 |
| 5 | INT | I/O 扩展芯片（输入） |
| 6 | RST | I/O 扩展芯片，有 10 kΩ 上拉 |

位置：主板背面，上边缘，J8 左边（从正面看的坐标：第 1 脚距左边 3.75 mm，第 6 脚 6.25 mm）。6 脚，0.5 mm 间距。

触摸芯片的 I²C 地址不能和板上已有的冲突：扩展芯片 0x20、0x22，充电芯片 SY6970（0x6A），摄像头（OV2640 是 0x30，
前摄待定，常见的占 0x21）。

## 7. 还没定、会影响排线的事

1. **上接还是下接。** 同一条排线插上接座和下接座，第 1 脚的位置正好相反。要按屏在整机里的位置、排线怎么弯到主板背面来定。
   定下来之后，请屏厂在排线图上标出金手指朝向，我们按 1:1 打印核对一次再开模。
2. **排线长度和弯折。** 取决于屏和主板在整机里的相对位置，由结构给出。
3. **座子型号。** 定了上接或下接、排线厚度之后选。
