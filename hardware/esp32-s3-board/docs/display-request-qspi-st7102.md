# 屏打样要求：QSPI 版本（ST7102，给屏厂）

日期：2026-11-12，2026-11-13 加上触摸。

## 1. 一句话要求

2.8 英寸、480 × 640、驱动芯片 ST7102 的屏，图像和命令都走 **QSPI**（CS、SCK、D0 ~ D3），排线按第 3 节的 22 脚定义出；**带电容触摸**，触摸排线按第 3.1 节的 6 脚定义出。
先做 3 ~ 5 片样品，屏和触摸一起打样。

## 2. 接口要求

| 项目 | 要求 |
|---|---|
| 尺寸、分辨率 | 2.8 英寸，480 × 640，竖屏 |
| 图像和命令接口 | **QSPI**：CS、SCK、D0 ~ D3，命令和图像都走这一组线。我们的主控没有 MIPI，引脚也不够做 RGB 并口，所以 MIPI 和并口都用不了 |
| 撕裂同步 | 需要 TE 输出，引到排线上 |
| 复位 | RESET，低有效 |
| 逻辑电平 | 3.3 V |
| 供电 | 主板只给一路 3.3 V。芯片如果还要 1.8 V 或别的电压，请在屏内部解决，或者告诉我们 |
| 像素格式 | RGB565（每个像素 16 位） |
| SCK 频率 | 我们计划用 40 MHz，请告诉我们最高能到多少 |
| 背光 | **灯必须串联**，电流 20 mA，4 ~ 6 颗串联都可以（约 12 ~ 20 V）。主板的背光是升压恒流电路，**并联的灯用不了**。你们现有的 LX280BS 规格书上是 4 颗并联，这一点要改 |
| 触摸 | 要，电容触摸，单独一条 6 脚排线，见第 3.1 节 |

## 3. 屏的信号（22 个，按这个顺序排）

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | LEDA | 电源 | 背光正极 |
| 2 | LEDK | 电源 | 背光负极 |
| 3 | VCC | 电源 | 3.3 V |
| 4 | GND | | 地 |
| 5 | CS | 主板 → 屏 | 片选 |
| 6 | SCK | 主板 → 屏 | 时钟 |
| 7 | GND | | 地，把时钟和数据隔开 |
| 8 | D0 | 双向 | 数据 |
| 9 | D1 | 双向 | 数据 |
| 10 | GND | | 地 |
| 11 | D2 | 双向 | 数据 |
| 12 | D3 | 双向 | 数据 |
| 13 | GND | | 地 |
| 14 | TE | 屏 → 主板 | 撕裂同步 |
| 15 | GND | | 地 |
| 16 | RESET | 主板 → 屏 | 复位，低有效 |
| 17 | GND | | 地 |
| 18 | GND | | 地 |
| 19 | NC | | 不接 |
| 20 | VCC | 电源 | 3.3 V |
| 21 | NC | | 不接 |
| 22 | VCC | 电源 | 3.3 V |

主板上的接口在主板背面的上边缘，用板对板公母座（见下面）。

**排线末端的做法：用亚奇品牌的板对板（BTB）公母座。**排线末端焊**公座**，主板上贴配套的**母座**。

- 请推荐亚奇的具体系列，给出**公座和母座的完整型号**（两者必须配套）、间距（常见 0.4 mm）、配合高度。配合高度希望 ≤1.0 mm，以结构最终确认为准。
- 上面的脚位表是**信号的顺序**。换成公母座后，请按所选型号的脚数重新排一张"母座脚号 → 信号"的对照表给我们：
  脚数比信号多的，多出的脚接地；公座和母座的脚号是镜像的，**对照表一律按主板上母座的脚号写**，避免两边对反。
- **触摸能并进同一个公母座的话，我们倾向并进**：触摸的小排线接到屏的排线上，屏和触摸从一个公座出来（比如 30 脚左右）。
  做不到就触摸单独一对小公母座。请告诉我们哪种可行。
- 排线上公座的位置、方向和背面的补强板，随排线图一起给。

## 3.1 触摸（一起打样）

屏上要带**电容触摸**。触摸优先并进屏的公母座（见上面）；并不进的话单独出一条排线，配一对小公母座。下表是触摸的 6 个信号。

| 项目 | 要求 |
|---|---|
| 类型 | 电容触摸，单点即可，支持两点更好 |
| 触摸芯片 | 建议 CST836U（I²C）；用别的芯片请告诉我们型号 |
| 结构 | 触摸盖板和屏贴成一体，请说明是全贴合还是框贴 |
| 接口 | I²C，主板上有 3.3 V 上拉；中断和复位低有效 |
| 供电 | 主板给 3.3 V。芯片如果只能用 2.8 V，请在触摸排线上自带稳压，或者告诉我们 |
| 排线 | 并进屏的公母座，或单独一对小公母座；从屏的哪边出、长度多少，请配合屏的排线一起给图 |

触摸的信号（并进屏的公母座时，按这个顺序排在屏的信号后面）：

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | TP-INT | 触摸 → 主板 | 中断，低有效 |
| 2 | TP-RST | 主板 → 触摸 | 复位，低有效 |
| 3 | TP-SCL | 主板 → 触摸 | I²C 时钟 |
| 4 | TP-SDA | 双向 | I²C 数据 |
| 5 | GND | | 地 |
| 6 | TP-VDD | 电源 | 3.3 V |

## 5. 我们的顾虑，请一起看

- **数据量。** 480 × 640、16 位色，一帧约 614 KB。QSPI 40 MHz 每秒最多送约 20 MB，整屏刷新最多约每秒 32 帧。
  我们要做摄像头取景和播放短片，希望整屏刷新能到每秒 20 帧以上。芯片如果没有显存，主控就得一直按这个速度送，压力很大。
- **先例。** 我们没找到这个主控用 QSPI 驱动 480 × 640 屏的公开例子。样品到了，我们先在开发板上点亮、测帧率，
  确认可行之后再改主板、开排线模具。

## 6. 样品到了我们怎么验

1. 用你们给的初始化代码点亮，显示彩条，颜色正确。
2. SCK 40 MHz 下长时间显示稳定，不花屏。
3. 测整屏刷新的实际帧率。
4. 用 TE 同步之后，画面移动时没有撕裂。
5. 同时开摄像头取景，画面稳定。
6. 触摸：用开发板的 I²C 读出触摸芯片的 ID，单点、两点触摸坐标正确，四个角和边缘都能点到。
