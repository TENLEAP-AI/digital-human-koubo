# 屏打样要求：QSPI 版本（ST7102，给屏厂）

日期：2026-11-12。

## 1. 一句话要求

2.8 英寸、480 × 640、驱动芯片 ST7102 的屏，图像和命令都走 **QSPI**（CS、SCK、D0 ~ D3），排线按第 3 节的 22 脚定义出。
先做 3 ~ 5 片样品。

## 2. 接口要求

| 项目 | 要求 |
|---|---|
| 尺寸、分辨率 | 2.8 英寸，480 × 640，竖屏 |
| 图像和命令接口 | **QSPI**：CS、SCK、D0 ~ D3，命令和图像都走这一组线。我们的主控没有 MIPI，引脚也不够做 RGB 并口，所以 MIPI 和并口都用不了 |
| 撕裂同步 | 需要 TE 输出，引到排线上 |
| 复位 | RESET，低有效 |
| 逻辑电平 | 3.3 V |
| 供电 | 主板只给一路 3.3 V。芯片如果还要 1.8 V 或别的电压，请在屏内部解决，或者告诉我们 |
| 像素格式 | RGB565（每个像素 16 位） |
| SCK 频率 | 我们计划用 40 MHz，请告诉我们最高能到多少 |
| 背光 | **灯必须串联**，电流 20 mA，4 ~ 6 颗串联都可以（约 12 ~ 20 V）。主板的背光是升压恒流电路，**并联的灯用不了**。你们现有的 LX280BS 规格书上是 4 颗并联，这一点要改 |
| 触摸 | 不要，触摸另配 |

## 3. 排线脚位（22 脚，0.5 mm 间距）

| 脚 | 名称 | 方向 | 说明 |
|---|---|---|---|
| 1 | LEDA | 电源 | 背光正极 |
| 2 | LEDK | 电源 | 背光负极 |
| 3 | VCC | 电源 | 3.3 V |
| 4 | GND | | 地 |
| 5 | CS | 主板 → 屏 | 片选 |
| 6 | SCK | 主板 → 屏 | 时钟 |
| 7 | GND | | 地，把时钟和数据隔开 |
| 8 | D0 | 双向 | 数据 |
| 9 | D1 | 双向 | 数据 |
| 10 | GND | | 地 |
| 11 | D2 | 双向 | 数据 |
| 12 | D3 | 双向 | 数据 |
| 13 | GND | | 地 |
| 14 | TE | 屏 → 主板 | 撕裂同步 |
| 15 | GND | | 地 |
| 16 | RESET | 主板 → 屏 | 复位，低有效 |
| 17 | GND | | 地 |
| 18 | GND | | 地 |
| 19 | NC | | 不接 |
| 20 | VCC | 电源 | 3.3 V |
| 21 | NC | | 不接 |
| 22 | VCC | 电源 | 3.3 V |

主板上的排线座：22 脚、0.5 mm 间距、翻盖式，在主板背面的上边缘。上接还是下接还没定，可以配合你们排线金手指的朝向来选。
如果你们觉得别的脚位顺序更好出线，可以提出来，我们主板这一部分还没有定稿。

## 4. 打样前请书面答复

| # | 问题 | 屏厂答复 |
|---|---|---|
| 1 | **ST7102 能不能用 QSPI 送图像数据，而不只是发命令？** 请把规格书里讲 QSPI 的那几页发给我们：接口怎么选、时序图、写图像的指令码 | |
| 2 | **芯片里有没有显存（GRAM）？** 没有的话，主控要按什么节拍一直送数据，最低刷新率是多少 | |
| 3 | QSPI 的协议：写命令和写图像各用什么指令码，命令走 1 根线还是 4 根线，SCK 最高多少 | |
| 4 | QSPI 模式下的完整初始化代码 | |
| 5 | 支持哪些像素格式；局部刷新时起止坐标有没有限制（比如必须是 2 或 4 的倍数） | |
| 6 | TE 能不能引到第 14 脚 | |
| 7 | 只给一路 3.3 V 行不行；屏的电流多大 | |
| 8 | 背光能不能改成串联；几颗灯、电压、电流 | |
| 9 | 排线图：长度、从模组哪边出线、弯折位置、金手指朝哪一面、第 1 脚在哪边 | |

**第 1、2 条最要紧。** 第 1 条不成立，这个方案就做不了。第 2 条决定我们的主控忙不忙得过来。

## 5. 我们的顾虑，请一起看

- **数据量。** 480 × 640、16 位色，一帧约 614 KB。QSPI 40 MHz 每秒最多送约 20 MB，整屏刷新最多约每秒 32 帧。
  我们要做摄像头取景和播放短片，希望整屏刷新能到每秒 20 帧以上。芯片如果没有显存，主控就得一直按这个速度送，压力很大。
- **先例。** 我们没找到这个主控用 QSPI 驱动 480 × 640 屏的公开例子。样品到了，我们先在开发板上点亮、测帧率，
  确认可行之后再改主板、开排线模具。

## 6. 样品到了我们怎么验

1. 用你们给的初始化代码点亮，显示彩条，颜色正确。
2. SCK 40 MHz 下长时间显示稳定，不花屏。
3. 测整屏刷新的实际帧率。
4. 用 TE 同步之后，画面移动时没有撕裂。
5. 同时开摄像头取景，画面稳定。
