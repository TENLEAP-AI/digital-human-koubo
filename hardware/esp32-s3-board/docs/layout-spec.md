# 主板 PCB 布局布线规范（六层版，草案 V0.1）

适用于 Zeebuddy 主板 V1（ESP32-S3-WROOM-1U + Air780E，64 × 34 mm，两面贴件）改成六层之后的布局布线。
原理图和引脚分配见 [requirements.md](requirements.md) 和 `../kicad/`。

**怎么读这份规范**

- 每条规则有编号（如 `PWR-3`），评审和检查时按编号对。
- "级别"：**必须** = 不满足不能投板；**建议** = 做不到要写明原因。
- "检查"：**DRC** = 写进 KiCad 的规则，软件自动查；**脚本** = 用脚本量出数字；**人工** = 对着图看。
- "依据"：**你** = 你提的四条要求；**合宙** = 合宙 Air780E 的设计指导文档；**估算** = 我用公式算的；
  **经验** = 通用的工程做法，是我的判断。
- 标 **待确认** 的数字现在只是占位，要板厂或你给了信息才能定。

## 1. 叠层和各层用途

| 层 | 名称 | 用途 | 说明 |
|---|---|---|---|
| L1 | 正面 | 元件 + 短线 | "低"的一面：小元件、前摄和按键的排线座、麦克风 |
| L2 | 地 | 整层地 | 正面所有线的回流层，不走线 |
| L3 | 信号 | 主要走线层 | 夹在 L2 地和 L4 之间，长线、总线、时钟优先走这里 |
| L4 | 电源 + 信号 | 3.3 V 铺铜、电池电源的铜皮、少量信号 | 天线线下方的这一小块改成地（见第 5 节） |
| L5 | 地 | 整层地 | 背面所有线的回流层，不走线 |
| L6 | 背面 | 元件 + 短线 | "高"的一面：两个模组、对外的接口、天线线、USB |

| 编号 | 规则 | 级别 | 检查 | 依据 |
|---|---|---|---|---|
| STK-1 | L2、L5 只铺地，不走任何线。唯一例外是天线线下方的挖空（RF-3） | 必须 | DRC | 经验 |
| STK-2 | L3 以横向走线为主，L4 以纵向为主；两层的线不允许上下重叠平行走超过 5 mm | 建议 | 人工 | 经验 |
| STK-3 | 只用通孔，不用盲孔、埋孔 | 必须 | DRC | 成本 |
| STK-4 | 外层铜厚 1 oz，内层 0.5 oz（**待确认**：以板厂的标准叠层为准） | — | 下单 | — |
| STK-5 | 板厚 0.8 mm（**待确认**，见下） | — | 下单 | — |

**板厚待确认**：搜索到的信息显示嘉立创六层板可以选 0.8 mm 板厚，但它公开的"带阻抗的六层叠层"只列了
1.2 / 1.6 / 2.0 mm。这两条都来自搜索结果的摘要，嘉立创的页面在我这边打不开，没有核实原文。
所以要先在嘉立创下单页确认：**0.8 mm 的六层板能不能做阻抗控制**。不能的话有两条路：
改 1.0 或 1.2 mm 板厚（要核对外壳），或者换一家能做的板厂。

## 2. 布线顺序（我打算怎么布）

1. **定叠层和规则。** 拿到板厂的叠层后，用板厂的阻抗计算器算出天线线和 USB 的线宽线距，写进 KiCad 的规则。
2. **按规范复查摆放。** 先改已知不符合的地方（见第 12 节），再开始布线。
3. **先布关键线，布完锁定**，顺序是：
   天线线 → 电源铜皮（电池、Air780E、充电）→ 三个开关电源的回路 → 去耦电容到引脚 → USB 四段差分线 → 时钟线。
4. **扇出。** 两个模组和各排线座的引脚先用短线加过孔引到 L3 / L4。
5. **布其余的线。** 长的总线（摄像头、屏）走 L3，纵向连接走 L4，短连接留在 L1 / L6。
   用自动布线（我自己的程序扩展到四个走线层，或者 Freerouting）完成，L2 / L5 不参与。
6. **铺铜和打地孔。** L1 / L6 空余处铺地，L4 铺 3.3 V，按规则补地孔。
7. **检查。** KiCad DRC（含本规范的自定义规则）、脚本量数字出一张"规则 — 实测 — 是否通过"的表、
   原理图一致性。全部通过后再交给人评审。
8. **人工评审。** 投板前最好请一位有经验的布线工程师按这份规范过一遍。我看不了图形界面，
   也没有实物验证过这块板，自动检查不能代替这一步。

## 4. 电源

### 设计电流（定铜皮宽度用）

| 网络 | 设计电流 | 来历 |
|---|---|---|
| 电池 → 充电芯片 → 系统（VBAT、VSYS） | 3 A | 4G 发射 + 3.3 V + 功放 + 背光同时工作，留余量 |
| Air780E 供电（VDD_4G） | 2 A | **假设**：合宙手册里没查到峰值电流，按同类 Cat.1 模组常用的余量取 |
| Type-C 输入（VBUS） | 2 A | 硬件限流约 0.53 A，按固件以后可能调高留余量 |
| 3.3 V 主干 | 1 A | ESP32 发射峰值约 0.5 A，加屏、摄像头、卡 |
| 喇叭输出 | 1 A | 功放满功率 |

铜皮载流（估算，IPC-2221，温升 10 °C）：外层 1 oz 走 1 / 2 / 3 A 分别要 0.30 / 0.78 / 1.37 mm；
内层 0.5 oz 走 1 / 2 A 要 1.56 / 4.07 mm。所以**大电流尽量留在外层**，上内层就必须是大块铜皮。

| 编号 | 规则 | 级别 | 检查 | 依据 |
|---|---|---|---|---|
| PWR-1 | VBAT、VSYS、VDD_4G 用铜皮，不用线。外层最窄处 ≥ 2.0 mm；焊盘入口处允许收窄到 1.0 mm，长度 ≤ 2 mm | 必须 | 脚本 | 你 |
| PWR-2 | 电池焊盘到 Air780E 供电脚，铜皮总长 ≤ 30 mm；铜皮电阻 ≤ 15 mΩ（1 oz 约 0.5 mΩ / 方块） | 必须 | 脚本 | 你、估算 |
| PWR-3 | Air780E 的 220 µF（C19）正极焊盘到模组供电脚 ≤ 1.0 mm，并且电容在电流的必经之路上，不是挂在旁边的支路 | 必须 | 脚本 | 你、合宙 |
| PWR-4 | C19 的地焊盘旁边打 ≥ 3 个 0.3 mm 地孔，离焊盘 ≤ 1 mm | 必须 | 脚本 | 经验 |
| PWR-5 | Air780E 的小滤波电容放在供电脚正对面（另一面），过孔紧挨焊盘 | 必须 | 脚本 | 合宙 |
| PWR-6 | 电源的保护管（TVS）放在电源进来的那一端，电流先过保护管 | 必须 | 人工 | 合宙 |
| PWR-7 | VBAT、VSYS、VDD_4G 换层时用 ≥ 4 个 0.3 mm 过孔；VBUS 和 3.3 V 主干 ≥ 2 个 | 必须 | 脚本 | 经验 |
| PWR-8 | VBUS 从 Type-C 到充电芯片线宽 ≥ 0.8 mm | 必须 | DRC | 估算 |
| PWR-9 | 开关电源（充电、3.3 V 降压、背光升压）：输入电容、输出电容紧贴芯片引脚，电容的地和芯片的地在**同一面**直接用铜皮连，不靠过孔绕到别的层 | 必须 | 人工 | 合宙 |
| PWR-10 | 开关节点（芯片到电感）的铜尽量小，长度 ≤ 3 mm，不打过孔，不铺大铜皮 | 必须 | 脚本 | 合宙 |
| PWR-11 | 反馈线从输出电容取，0.15 mm，离电感和开关节点 ≥ 1 mm | 必须 | 人工 | 经验 |
| PWR-12 | 充电芯片底部散热焊盘打 ≥ 5 个地孔；功放底部散热焊盘 ≥ 4 个 | 必须 | 脚本 | 经验 |
| PWR-13 | 3.3 V 用 L4 的铺铜分配，每个用电点自己打孔取电 | 建议 | 人工 | 经验 |
| PWR-14 | 喇叭两根输出线 ≥ 0.4 mm，并排走，离麦克风和天线线 ≥ 3 mm | 必须 | 脚本 | 经验 |
| PWR-15 | 背光升压输出到屏的两根线 0.25 mm，与其它线间距 ≥ 0.2 mm（这里电压最高到 30 V） | 必须 | DRC | 经验 |

**实物验收**：电池 3.6 V、4G 满功率发射时，用示波器量模组供电脚，跌落 ≤ 300 mV 且不低于 3.3 V
（3.3 V 是合宙给的供电下限；300 mV 是我定的目标）。

## 5. 4G 天线线

这块板**没有板载天线**。4G 走 IPEX 座（J7）接外置天线，Wi-Fi 用 ESP32 模组自带的 IPEX 座，板上没有 Wi-Fi 射频线。
所以这里管的是"模组天线脚 → 匹配元件 → IPEX 座"这一段传输线。

**结构**：线在 L6（背面）；它正下方的 L5 挖空，以 L4 的地作参考；L6 上线的两侧铺地（共面波导）。
这是合宙对多层板的推荐做法。原因是六层板外层离相邻地层只有约 0.1 mm，直接参考 L5 的话 50 Ω 的线只有
约 0.17 mm 宽（估算），比 0402 焊盘和天线座焊盘窄得多，阻抗不连续；挖掉 L5 后线可以加宽到 0.4 mm 左右。

| 编号 | 规则 | 级别 | 检查 | 依据 |
|---|---|---|---|---|
| RF-1 | 特征阻抗 50 Ω ± 10%，整段都要控制。线宽和两侧间隙用板厂阻抗计算器按实际叠层算（**待确认**） | 必须 | 板厂 | 你、合宙 |
| RF-2 | 只走 L6，不打过孔，不分叉 | 必须 | DRC | 合宙 |
| RF-3 | 线的正下方 L5 挖空，宽度 = 5 倍线宽，沿线全长，包括匹配元件和天线座信号焊盘下方 | 必须 | 脚本 | 合宙 |
| RF-4 | 挖空区正下方的 L4 是完整的地，比挖空区每边多出 ≥ 1 mm，中间不走任何线 | 必须 | DRC | 合宙 |
| RF-5 | 线两侧的地铜上打地孔，间距 ≤ 2 mm，把 L6、L5、L4、L2 的地连起来 | 必须 | 脚本 | 合宙、估算 |
| RF-6 | 模组脚到天线座总长 ≤ 15 mm（四层版是 8.7 mm） | 必须 | 脚本 | 合宙 |
| RF-7 | 拐弯用 135° 或圆弧 | 必须 | 人工 | 合宙 |
| RF-8 | π 型匹配（R49 串联、C29 / C30 并联）紧挨天线座；并联电容的焊盘直接压在线上，不引支线；电容的地焊盘旁各打一个地孔 | 必须 | 人工 | 合宙 |
| RF-9 | 相邻层没有与它平行或交叉的信号线；L6 上其它信号离它 ≥ 1 mm | 必须 | DRC | 合宙 |
| RF-10 | 电感、开关节点、喇叭输出离天线线和天线座 ≥ 5 mm | 建议 | 脚本 | 合宙 |
| RF-11 | 天线座的每个地焊盘旁打 ≥ 2 个地孔 | 必须 | 脚本 | 经验 |
| RF-12 | 下单时把这段线标出来，要求板厂做阻抗控制并提供阻抗报告 | 必须 | 下单 | 合宙 |

RF-5 的 2 mm：合宙给的最高频率约 2.66 GHz，板上波长约 64 mm，二十分之一是 3.2 mm，取 2 mm 留余量（估算）。

**"天线下方净空"放在哪**：净空针对的是天线本体。外置天线贴在外壳里的位置，附近不要有电池、屏的金属背板、
喇叭，4G 和 Wi-Fi 两根天线要分开。具体距离以天线厂的规格书为准，并且要在外壳设计阶段就找天线厂评估（合宙）。

## 6. USB

涉及四段：Type-C（J1）→ 保护器件（U1）→ 切换芯片（U6）→ Air780E；以及切换芯片 → ESP32。
Air780E 那一路是高速 USB，按最严的要求做；ESP32 那一路速度低，但用同一套规则。

| 编号 | 规则 | 级别 | 检查 | 依据 |
|---|---|---|---|---|
| USB-1 | 差分阻抗 90 Ω ± 10%，线宽线距用板厂计算器算（**待确认**） | 必须 | 板厂 | 合宙 |
| USB-2 | 每一段的两根线全程并排、同层、同时换层，间距固定 | 必须 | DRC | 你、合宙 |
| USB-3 | 对内长度差：每段 ≤ 0.5 mm，从接口到芯片整条路径 ≤ 1.0 mm。从焊盘量到焊盘，不算分支 | 必须 | 脚本 | 你 |
| USB-4 | 长度补偿（绕线）做在产生长度差的那一端附近 | 建议 | 人工 | 经验 |
| USB-5 | 每根线换层 ≤ 2 次；两根线的过孔并排对称，旁边各配一个地孔 | 必须 | 脚本 | 合宙 |
| USB-6 | 不留分支：测试点（TP14 / TP15）直接压在线上；保护器件串在线上，线从它的焊盘穿过 | 必须 | 脚本 | 合宙 |
| USB-7 | 保护器件紧挨 Type-C 座，寄生电容 < 1 pF | 必须 | 人工 | 合宙 |
| USB-8 | 差分对与其它信号间距 ≥ 0.5 mm，与时钟线、开关节点 ≥ 1.0 mm | 必须 | DRC | 经验 |
| USB-9 | 走线下方的参考层连续，不跨铺铜的缝 | 必须 | 人工 | 经验 |

USB-3 说明：常见的设计指南给高速 USB 的上限是 150 mil（约 3.8 mm），这里收紧到 1.0 mm。
四层版量到的是 1.5 / 0 / 0.9 / 2.2 mm，不满足。

估算的初值（外层、离地 0.1 mm）：线宽约 0.17 mm、间距 0.15 mm。只用来占位，以板厂计算结果为准。

## 9. 地和铺铜

| 编号 | 规则 | 级别 | 检查 |
|---|---|---|---|

| GND-2 | L1、L6 空余处铺地，孤立的小铜皮去掉；铺铜与线的间距 0.2 mm | 必须 | DRC |
