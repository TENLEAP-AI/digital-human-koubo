# 同类产品的电源管理芯片调查

日期：2026-11-18。目的：看和我们配置相近的产品（ESP32 + 屏 + 摄像头 + 单节锂电池，部分带 4G）都用哪种充电和电源管理芯片，确认我们现在的 SY6970 + SY8089 选得对不对。

## 1. 调查方法

不靠网上的介绍文章，直接看实际产品的原理图和驱动代码：

- **小智 AI 开源项目**（github.com/78/xiaozhi-esp32）：收录了 168 个国内外 ESP32 AI 硬件的板级配置，代码里能看出每块板用什么芯片管电池。
- **乐鑫、LilyGO 公开的原理图**：直接从原理图里读芯片型号。

## 2. 结果

### 2.1 小智 AI 项目里带电池的板子

| 管理方式 | 板子 | 说明 |
|---|---|---|
| **AXP2101**（芯片集成充电、电量计和多路电源） | M5Stack CoreS3（带摄像头和屏）、M5Stack StackChan、Kevin Box-2（带 4G）、微雪十几款带屏的板子 | 国外开发板和"高配"产品用得最多 |
| **SY6970**（开关充电，带电源路径） | LilyGO T-CameraPlus-S3（摄像头 + 屏）、LilyGO T-Display-S3-Pro | 驱动现成，项目里有 `sy6970.cc` |
| **简单线性充电 + 主控测电池电压** | 正点原子 BOX2-4G、正晨 cam-ml307（摄像头 + 4G）、星智、CyberAI、Magiclick 等约 20 款，**国内带 4G 的小智盒子几乎都是这种** | 成本最低。充电芯片型号在代码里看不出来，一般是 TP4054 / TP4056 这类 |
| 加独立电量计 BQ27220 | 乐鑫 ESP-Mosaico、LilyGO T-Display-P4、微雪 7 寸屏 | 电量百分比更准 |
| 厂家自研 | M5Stack StickS3、CoreP4X（M5PM1） | 不通用 |

## 3. 三种做法对比

| | SY6970（现在用的） | AXP2101 | 线性充电 + 测电压 |
|---|---|---|---|
| 充电方式 | 开关充电，效率高、发热小，最大 3 A 以上 | 线性充电，约 1 A，1 A 充电时芯片发热约 1 W 多 | 线性，0.5 ~ 1 A，发热同左 |
| 边充边用 | **有电源路径**：插着电时整机直接用 USB 供电，电池没电也能马上开机 | 有电源路径 | 一般**没有**，电池耗尽时插电，4G 一发射可能重启 |
| 电量显示 | 能读电池电压，百分比靠估算 | 自带电量计，较准 | 只能读电压，最不准 |
| 能不能顺便给别的器件供电 | 不能，另配 3.3 V 降压 | 能，自带 5 路降压 + 11 路 LDO，可以省掉 SY8089 和摄像头的两颗 LDO | 不能 |
| 软件 | 小智项目、LilyGO 都有现成驱动 | 小智项目、M5Stack 都有现成驱动 | 最简单 |
| 第二货源 | **TI BQ25895 脚位相同** | 只有 X-Powers 一家 | 很多 |
| 成本 | 中 | 中偏高（但省掉几颗器件） | 最低 |

## 4. 结论

1. **保留 SY6970 + SY8089，不换。** 和我们最接近的产品（LilyGO 带摄像头和屏的板子）用的就是这一套。我们同时有 4G 发射、16 位屏、两个摄像头和 3 W 功放，峰值电流大，又要边充边用，**电源路径和开关充电是必须的**，线性充电那套不适合。
2. **国内带 4G 的小智盒子大多用便宜的线性充电**，那是为了压成本，产品也小（没有大屏和摄像头），不值得照搬。
3. **AXP2101 是另一个可选项**：器件少、自带电量计，但充电是线性的，1 A 充电时发热明显，而且只有一家货源。现在原理图已经按 SY6970 画好，不建议为此重画。
4. **建议加一颗电量计**（BQ27220，或国产赛微 CW2015），让电量百分比准一点，小朋友和家长对"还剩多少电"很敏感。它挂在现有的 I²C 总线上，地址（BQ27220 是 0x55，CW2015 是 0x62）和板上其他器件不冲突，可以先留位置不贴。要加的话我在原理图上补。
