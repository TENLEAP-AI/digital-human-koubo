# 乐鑫官方资源：AI 拍学机能用上的（ESP32-S31）

日期：2026-11-14。读的是乐鑫官网中文版（espressif.com/zh-hans，内容和 espressif.com.cn 相同）、S31 开发者站、ESP-VISION、私有化智能体平台、
各 SDK 的 GitHub 说明、组件库和开发者门户。没读到的页面列在第 7 节。下面的数字都来自乐鑫的页面或仓库说明，没有自己估。

## 1. 结论

拍学机的每个功能，乐鑫都有现成的东西可以用，而且大部分已经支持 S31。三件事要特别注意：

1. **屏驱动：两家都照常打样。**NV3049F 在乐鑫组件库里没有驱动，要按屏厂的初始化代码自己写。ST7102 有第三方驱动（`kevincoooool/esp_lcd_st7102`，Apache-2.0，RGB / MIPI 模式），同一作者还有一块 **S31 + ST7102 的 4.3 寸板级参考**，说明 ST7102 在 S31 上跑过，可以借鉴；我们用的 QSPI 模式仍要联讯给初始化代码。
2. **S31 模组目前查不到无线认证证书（SRRC、CE、FCC 都没有）**，规格书也还是预发布版。量产前必须问清楚乐鑫什么时候出证。
3. **安全启动不能用 ECDSA 方式**。S31 当前芯片版本有一个已公开的漏洞（AR2026-006），乐鑫建议用 RSA 方式的安全启动。

## 2. 按功能对照

| 拍学机功能 | 用乐鑫的什么 | S31 支持 | 要点 |
|---|---|---|---|
| **拍题讲解**（拍照 → 发给大模型 → 讲解） | ESP-ADF v3 的 `ai_agent` 例程，其中**通义千问看图例程**：按一下拍一张 JPEG，带着图片提问 | 有 S31-Korvo-1 的配置 | 最接近我们的产品，改造起点。还有火山、扣子、百度三个例程 |
| 语音唤醒、离线命令词 | ESP-SR：WakeNet 唤醒词、MultiNet 离线命令词（最多 300 条） | 列了 S31，乐鑫写的是"初步支持" | 自定义唤醒词要走乐鑫流程或自己训练，费用没写 |
| 降噪、回声消除（边放边说） | ESP-SR 的 AFE 声学前端 | 同上 | 单麦克风方案能用。S3 上约占 22% CPU、1.1 MB PSRAM，S31 没给数据 |
| 摄像头取景、拍照 | `esp_video` + `esp_cam_sensor` | 支持，**硬件 JPEG 编码** | **OV2640 在支持列表里**。前摄可从 GC0308、GC032A、BF3A03、SC030IOT 里选（都在支持列表里） |
| 端侧框出题目区域 | ESP-DL（推理框架）+ 自己训练检测模型 | 支持 | 文字识别（OCR）模型**只支持 P4**，S31 上不做 OCR，识别交给云端 |
| 显示和界面 | LVGL + `esp_lvgl_port` + PPA（硬件旋转缩放） | 支持 | S31 官方实测：800 × 480 屏 LVGL 跑分每秒 50 帧，我们的 480 × 640 更轻松 |
| 界面系统框架 | ESP-Brookesia（带智能体接入和视频服务） | 要 ESP-IDF 6.2，还不稳定 | 可参考，暂不依赖 |
| 播放英语视频 | ESP-GMF 的 `esp_player` | 有 S31 实测 | **MJPEG 硬件解码 640 × 480 每秒 66 帧；H.264 只能软解，同分辨率约 13 帧**。片源统一转成 MJPEG |
| 跟读慢放、音量和音质 | ESP-Audio-Effects：变速不变调（0.5 ~ 2 倍）、均衡、限幅 | 1.3.0 版起支持 S31 | 跟读功能直接能用 |
| 4G 上网（Air780E） | `iot_usbh_modem` + `usb_host_cdc_acm` | 组件列了 S31 | 说明文字里只写了 S2 / S3 / P4，Air780E 在不在兼容列表要确认 |
| 实时语音对话（可选） | ESP-WebRTC | 有 S31 预编译库 | 只有选 RTC 类云端（火山 RTC、声网等）时才用 |
| 云端智能体后台（可选） | 乐鑫私有化智能体平台（部署在自己的 AWS） | 设备固件未支持 S31 | 国内能不能用要问；国内大模型直接接更现实 |
| 设备管理、OTA、家长 App（可选） | ESP RainMaker Neo（2026-08 开源） | 说明里没列 S31 | 跑在 AWS 上，国内部署没提。可自建 OTA 代替 |
| 远程诊断 | ESP Insights | 没写 | 只能接乐鑫或 RainMaker 的云 |
| 快速原型 | ESP-VISION（MicroPython 低代码视觉，已装进 Claude Code） | 支持 Korvo-1 | S31 版暂时关了 TLS，不能做 HTTPS 上传，只适合验证取景和检测 |

**许可**：ESP-ADF、ESP-SR、esp_video、ESP-GMF 是"乐鑫修改版 MIT"，**只允许用在乐鑫芯片上**，对我们没问题；ESP-DL 是 MIT；
esp-iot-solution、esp_cam_sensor、ESP-VISION 是 Apache-2.0。各家大模型的费用和延迟乐鑫没写，要分别问。

## 3. 建议的软件路线

1. **以 ESP-ADF v3 的通义看图例程为起点**，在 Korvo-1 上先跑通"按键 → 拍照 → 问大模型 → 语音讲解"。
2. 加 ESP-SR 的唤醒词和回声消除，做语音问答。
3. 摄像头用 `esp_video`，拍照走硬件 JPEG；界面用 LVGL。
4. 网络先用 Wi-Fi 验证，再换 `iot_usbh_modem` 走 4G。
5. 视频、音频播放用 `esp_player`，片源转 MJPEG + AAC / MP3。
6. 云端和设备管理先自建（国内云），RainMaker、私有化智能体平台等问清国内可用性再说。

注意：这些框架有的要求 ESP-IDF v6.1，有的要求 6.2（还在开发），**固件开工前要统一 ESP-IDF 版本**。

## 4. 对硬件和量产的影响

| 项目 | 影响 | 落到哪 |
|---|---|---|
| 前摄选型 | 选 `esp_cam_sensor` 支持的型号：GC0308、GC032A、BF3A03、SC030IOT | 定前摄料号时优先这几颗 |
| 视频走 MJPEG | 数据量比 H.264 大，靠 TF 卡 4 线读取。TF 卡吞吐乐鑫没给 S31 数据 | 开发板上实测 |
| Wi-Fi 天线 | 模组认证用的天线增益是 **2.33 dBi**。我们选的天线增益不能超过它，否则可能要补测 | 选 Wi-Fi 天线时注意 |
| 工厂烧录 | 乐鑫的 1 拖 4 治具只适配 WROOM-3，**没有 WROOM-1U 的治具** | 主板要留烧录测试点（USB D+ / D−、串口、BOOT、EN、3.3 V、GND），自己做治具 |
| 安全 | 用 RSA 安全启动 + 发布模式 Flash 加密，关闭或限制下载模式；签名私钥放进加密设备 | 固件和产线流程 |
| 乐鑫代工服务 | 可以预烧加密固件、写一机一码、预置设备证书、出货清单。小批量能不能做、多少钱，没写 | 问乐鑫 |
| 设计审阅 | 原理图和 PCB **免费审阅，1 ~ 3 个工作日**，限商业项目 | 原理图改完就提交 |
| 供货 | S31 承诺供货 12 年以上（从 2026 年起） | — |

## 5. 认证

- S31-WROOM-1U 在乐鑫文档中心**查不到任何 SRRC、CE、FCC 证书**，只有环保合规声明等。
- 乐鑫的认证协助服务列了 SRRC、FCC、CE 等，**没有提 CCC**。
- 就算模组有证，整机还是要按销售地区做认证；Air780E 的认证另问合宙。
