## IO 预算

### 可用引脚

按 ESP32-S3-WROOM-1U-N16R8（16 MB Flash、8 MB PSRAM、IPEX 天线座）计算。
模组引出 36 个 GPIO，其中 GPIO35 / 36 / 37 被 8 MB PSRAM 占用，**可用 33 个**：GPIO0 ~ 21、GPIO38 ~ 48。

### 放到 IO 扩展芯片上的慢信号（不占原生 GPIO）

用一颗 16 位 I²C 扩展芯片（XL9555 / TCA9555 一类），正好 16 路：

| 信号 | 路数 |
|---|---|
| 按键 KEY1 ~ KEY6 | 6 |
| Air780E：开机 PWRKEY、关机 RESET、状态 STATUS、DTR、电源使能 | 5 |
| 屏复位、触摸复位 | 2 |
| 前摄待机、后摄待机（切换前后摄） | 2 |
| 功放使能 | 1 |

不接或不占引脚的：摄像头复位（接上电复位电路，软件复位走 I²C）、触摸中断（改为轮询）、
Air780E 的 RI（不接）、充电状态（走充电芯片的 I²C 或指示灯）、SIM 卡检测（接 Air780E）、复位键（直接接 ESP32 的 EN）。

### 方案一：SPI 屏 —— 够用，但全部用完

| 功能 | 原生 GPIO | 明细 |
|---|---|---|
| 摄像头（8 位并口，前后摄共用） | 12 | D0 ~ D7、PCLK、VSYNC、HREF、XCLK |
| 屏（四线 SPI） | 4 | CLK、MOSI、CS、DC |
| 背光调光 | 1 | PWM |
| 音频 | 4 | BCLK、WS、麦克风数据、功放数据（麦克风和功放共用时钟） |
| Air780E | 4 | TX、RX、RTS、CTS |
| I²C 总线 | 2 | 触摸、摄像头配置、扩展芯片、充电芯片共用 |
| USB | 2 | 下载、调试 |
| 扩展芯片中断 | 1 | 按键响应；休眠时按键唤醒 |
| 电池电压检测 | 1 | ADC |
| **小计（不含 TF 卡）** | **31** | 剩 2 个 |
| TF 卡（与屏共用 SPI 总线） | 2 | MISO、片选 |
| **合计（含 TF 卡）** | **33** | **剩 0 个** |

引脚分配草案（方案一，含 TF 卡）：

| GPIO | 用途 | 选这个脚的原因 / 注意 |
|---|---|---|
| 0 | 屏 DC | 启动配置脚：复位时必须为高。接的是屏的输入脚，不会被拉低。另留 BOOT 测试点 |
| 1 | 扩展芯片中断 | 属于休眠时仍可用的引脚，能用来唤醒 |
| 2 | 功放数据 | |
| 3 | 麦克风数据 | 启动配置脚，默认不起作用 |
| 4 ~ 8 | 摄像头 D0 ~ D4 | |
| 9 | 电池电压检测 | ADC1（Wi-Fi 工作时也能用的那组 ADC） |
| 10 / 11 / 12 | 屏 CS / MOSI / CLK | ESP32-S3 的专用高速 SPI 引脚 |
| 13 / 14 | TF 卡 MISO / 片选 | 与屏共用 MOSI、CLK |
| 15 / 16 | Air780E RTS / CTS | 串口 0 的专用流控引脚 |
| 17 / 18 / 21 | 摄像头 D5 ~ D7 | |
| 19 / 20 | USB D- / D+ | |
| 38 / 39 / 40 / 41 | 摄像头 PCLK / XCLK / VSYNC / HREF | |
| 42 / 46 | 音频 BCLK / WS | GPIO46 是启动配置脚，复位时要为低；接的都是输入脚，没问题 |
| 43 / 44 | Air780E 串口发 / 收 | 串口 0 的专用引脚，跑 921600 最稳 |
| 45 | 背光调光 | 启动配置脚，复位时必须为低；默认下拉，正好是"上电背光关" |
| 47 / 48 | I²C SDA / SCL | |

这个分配的代价：

- **没有任何备用引脚**。之后想加指示灯、4G 来数据唤醒主控、触摸中断等，都没有脚可用。
- **串口 0 给了 Air780E**，板上不再有独立的调试串口，调试和下载全靠 USB。
  ESP32-S3 上电时会从串口 0 打印启动信息，Air780E 会收到一小段乱码（它此时还没开机，无影响）。
- 四个启动配置脚（GPIO0、3、45、46）全部用上了，外接的器件在复位瞬间不能把它们拉到错误电平。
- 麦克风和功放共用时钟，两者必须用同一个采样率。

想留出余量，可以选下面的做法（每条省的引脚数写在后面）：

| 做法 | 省几个 | 代价 |
|---|---|---|
| 主板不带 TF 卡 | 2 | 没有本地存储扩展 |
| 用带 I²C 电压检测的充电芯片（BQ25895 一类）读电池电压 | 1 | 充电芯片选型受限 |
| 摄像头时钟用板上晶振，不由 ESP32 提供 | 1 | 多一颗晶振，待机功耗略增 |
| 屏的片选直接接地 | 1 | TF 卡不能再和屏共用总线 |
| Air780E 不接 RTS / CTS | 2 | 高波特率下可能丢数据，网速要降 |
| 改用 2 MB PSRAM 的模组（N16R2） | 多出 3 个 | 内存只有 2 MB，摄像头 + 界面 + 语音同时跑会很紧 |

### 方案二：ST7701 屏（480 × 640）—— 不够

乐鑫官方 LCD 指南说明，ST7701S 是"SPI + RGB"接口：三线 SPI 只发初始化命令，图像数据走 RGB 并口，
屏本身没有显存，主控要不停地送数据。ESP32-S3 驱动它要 16 根数据线 + 像素时钟 + 行同步 + 场同步 + DE，共 20 个引脚
（三线 SPI 可以挂在扩展芯片上）。ST7701 的另一种接法是 MIPI，ESP32-S3 不支持。

| | 引脚数 |
|---|---|
| 方案一里屏和背光以外的部分（不含 TF 卡） | 26 |
| ST7701 屏：20 + 背光 1 | 21 |
| 合计 | 47 |
| 可用 | 33 |
| **缺口** | **14** |

把还能省的都省掉（电池检测走 I²C、摄像头时钟用晶振、不接 RTS / CTS，共 4 个），仍然差 10 个。
即使不用模组、直接用芯片并外挂四线 PSRAM（可用 GPIO 增加到 38 个），也还差 5 个。
**结论：在要接并口摄像头的前提下，ESP32-S3 带不动 ST7701 屏。**

可选的出路：

1. **换一块真正用 SPI 传图像的屏**（驱动芯片带内置显存，比如 2.8 寸 240 × 320 的 ST7789）。
2. **坚持 480 × 640 的 ST7701 屏**：换主控（例如带 MIPI 的 ESP32-P4，另配一颗 Wi-Fi 芯片），整个方案重排。

## 其它待定

- 前后摄像头共用一组并口数据线时，要确认两颗传感器待机时数据脚是否为高阻；不是的话要加总线开关。
  前摄的具体型号还没定。
- 触摸芯片型号、屏的排线引脚定义和背光参数。
- 6 个按键是否包含开关机键；开关机用"长按进出休眠"还是"硬件断电"。
- TF 卡是否真的要用（影响是否有备用引脚）。
- 外形：是否要与参考主板的外形、螺丝孔和座子位置一致（等参考主板的 STEP 文件）。
- 电池容量和充电电流；是否需要电量计。
