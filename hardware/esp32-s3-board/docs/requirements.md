## 必须先解决：屏的接口与引脚数

之前说"屏用 SPI"，但 ST7701 的像素数据走的不是 SPI：

- 乐鑫官方 LCD 指南说明，ST7701S 是"SPI + RGB"接口：三线 SPI 只用来发初始化命令，
  图像数据走 RGB 并口（16 / 18 / 24 根数据线）。RGB 接口的屏没有内置显存，主控要不停地送数据。
- ESP32-S3 驱动这种屏要用 16 根数据线，加像素时钟和同步信号，共约 20 个引脚。
- ESP32-S3 不支持 MIPI，所以 ST7701 的 MIPI 接法也用不了。

引脚预算（按 ESP32-S3-WROOM-1U-N16R8 算，可用 GPIO 为 0 ~ 21 和 38 ~ 48，共 33 个）：

| 功能 | 原生 GPIO 数 | 说明 |
|---|---|---|
| 摄像头（8 位并口） | 12 | 8 数据 + PCLK、VSYNC、HREF、XCLK；配置线走 I²C |
| Air780E | 4 | TX、RX、RTS、CTS |
| 音频 | 4 | BCLK、WS、麦克风数据入、功放数据出（时钟共用） |
| I²C 总线 | 2 | 触摸、摄像头配置、IO 扩展芯片、传感器共用 |
| USB | 2 | GPIO19 / 20，下载和调试 |
| 中断 | 2 | 触摸、IO 扩展芯片 |
| 电池电压检测 | 1 | ADC |
| 背光调光 | 1 | PWM |
| **屏以外合计** | **28** | |
| 屏：真正的 SPI 屏 | 4 | CLK、MOSI、CS、DC → 合计 32，勉强放得下，没有余量 |
| 屏：ST7701（RGB 并口） | 约 20 | → 合计约 48，**超出 15 个，放不下** |

按键、各种复位和使能、Air780E 的开关机和状态等慢信号都放到 I²C 的 IO 扩展芯片上，不占原生 GPIO。

可选的出路：

1. **换一块真正用 SPI 传图像的屏**（驱动芯片带内置显存，比如 2.8 寸 240 × 320 的 ST7789）。这是 ESP32-S3 上最成熟的做法。
2. **坚持 480 × 640 的 ST7701 屏**：ESP32-S3 在同时接摄像头的情况下引脚不够，需要换主控
   （例如带 MIPI 的 ESP32-P4，另配一颗 Wi-Fi 芯片），整个方案要重排。
