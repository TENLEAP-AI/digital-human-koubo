# 主板 PCBA 规划（ESP32-S31 版，第一版打样 EVT）

日期：2026-11-14。主控已定 ESP32-S31，引脚见 [esp32-s31-pinmap.md](esp32-s31-pinmap.md)，屏在两家打样（[display-samples-two-makers.md](display-samples-two-makers.md)），
PCB 找外部工程师画（[pcb-redesign-brief.md](pcb-redesign-brief.md)）。

## 1. 目标

第一版打样（EVT）只回答一个问题：**这套方案能不能在一块板上全部跑起来**——屏、两个摄像头、4G、Wi-Fi、音频、TF 卡、充电同时工作，不出画面问题、不掉线、不重启。
外观、成本、量产工艺放到第二版（DVT）。

| 项目 | 第一版的做法 |
|---|---|
| 数量 | **10 块**：5 块整机装配，3 块单板调试，2 块备用（返修、做破坏性测试） |
| 板子 | 6 层、1.6 mm、64 × 34 mm（外形不变） |
| 贴片 | 两面贴，一次性交给一家做 PCB + 贴片 |
| 屏 | 两家屏只有一家先到样品、测试过关，就按那家画；两家都没定就**不投板** |

## 3. PCB 和贴片的工艺要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 层数、板厚 | 6 层，1.6 mm，外层 1 oz、内层 0.5 oz | 规范第 1 节 |
| 叠层 | 嘉立创六层阻抗叠层（外层 7628） | 下单时确认型号 |
| 阻抗控制 | 4G 天线线 50 Ω；两组 USB 90 Ω 差分 | 下单时标出，要阻抗报告 |
| 最小孔 | 0.2 mm 孔 / 0.45 mm 盘 | 这个板厚下的下限 |
| 过孔处理 | 全部盖油；**如果用盘中孔，要树脂塞孔 + 电镀盖帽** | 工程师给建议后定（改板说明第 7.1 节） |
| 表面处理 | 沉金 | 模组底部小焊盘、0.4 mm 间距器件，喷锡不平 |
| 贴片 | 两面贴。背面重件（两个模组、钽电容、卡座、Type-C）**第二次过炉** | 规范 DFM-1 |
| 检查 | AOI 全检；**两个模组和 QFN 芯片做 X 光抽检** | 模组底部焊盘看不到，只能靠 X 光 |
| 钢网 | 两面各一张；模组底部散热焊盘按规格书推荐开窗 | |
| 拼板 | 加工艺边和定位点，连接点避开 Type-C、SIM、TF、天线座 | 规范 DFM-5、6 |

## 4. 物料：要提前买的长交期和非标件

普通阻容、芯片交给板厂代采。下面这些**我们自己买或确认能代采**，打样前备齐（每样按 10 块 + 损耗备 15 ~ 20 套）：

| 物料 | 来源 | 状态 |
|---|---|---|
| ESP32-S31-WROOM-1U-N16R16V | 乐鑫深圳授权代理（启明云端、科通、飞睿、中云信安）或乐鑫官方店 | **待询价、交期** |
| 合宙 Air780E | 合宙官方或代理 | 确认板厂库里有没有，没有就寄料 |
| 4G 天线、IPEX 线 | 天线厂 | 待定型号 |
| Wi-Fi 天线（模组 IPEX 座） | 天线厂 | 待定型号 |
| 屏 + 触摸 + 盖板总成 | 两家屏厂之一 | 打样中 |
| 亚奇公母座（屏和触摸） | 亚奇 / 屏厂推荐料号 | **待屏厂给料号** |
| 后摄 OV2640 模组、前摄 30 万模组 | 摄像头模组厂 | 前摄型号待定 |
| FPC 座（摄像头 24P ×2、按键 6P ×2） | 立创 / 原厂 | 要定实际料号换封装 |
| Type-C、Nano SIM 座、TF 卡座 | 立创 | 要定实际料号换封装 |
| 220 µF 低 ESR 钽电容（Air780E 供电） | 立创 | 不能用陶瓷电容代替 |
| 电池（2000 mAh）、喇叭、麦克风 | 供应商 | 电池温度电阻、充电参数待定 |

已经可以不要的：USB 切换芯片 FSUSB42、第二颗 XL9555、可能还有 24 MHz 晶振（摄像头时钟改由主控出，要在开发板上确认）。

### 4.1 读乐鑫资料后补充的（2026-11-14，见 [espressif-resources-for-ai-camera.md](espressif-resources-for-ai-camera.md)）

- **烧录测试点**：乐鑫没有 WROOM-1U 的烧录治具。主板正面留测试点：USB D+ / D−（GPIO34 / 33）、串口 TX / RX（GPIO59 / 58）、BOOT（GPIO61）、EN、3.3 V、GND，做自己的顶针治具。
- **前摄**：优先选乐鑫摄像头驱动支持的 GC0308、GC032A、BF3A03、SC030IOT。
- **Wi-Fi 天线**：增益不超过 2.33 dBi（模组认证用的天线），超过可能要补测。
- **认证**：S31-WROOM-1U 目前查不到 SRRC / CE / FCC 证书，打样不受影响，量产前必须问清。
- **设计审阅**：乐鑫免费审原理图和 PCB（1 ~ 3 个工作日），原理图改完就提交。

## 5. 成本（粗估，等精确 BOM）

之前按 S3 方案估的是：10 块打样每块约 180 ~ 190 元（元件约 100、贴片约 72、PCB 10 ~ 20），不含屏、摄像头、电池等。
换 S31 后的变化：主控模组价格待询（S31 首发芯片价约 4.5 美元，模组价格未知）；少一颗切换芯片、一颗扩展芯片；
**6 层板 + 阻抗 + 沉金 + 两面贴 + X 光比原来按 4 层估的贵不少**，打样一批（10 块）的板费和贴片费估计在 1500 ~ 3000 元，下单页报价为准。

原理图改完，我出一份带立创编号的精确 BOM 和报价。

## 6. 回来后怎么测（第一版验收）

按顺序做，前一步不过不往下走：

| # | 测什么 | 合格线 |
|---|---|---|
| 1 | 不接电池、不插卡，限流 0.5 A 用 5 V 上电，量各路电压（VSYS、3.3 V、2.8 V、1.2 V） | 电压对、没有短路、电流正常 |
| 2 | Type-C 接电脑，USB 口下载固件、看日志 | 能下载、能启动 |
| 3 | 电池上电、充电、拔插 Type-C 反复 50 次 | 不死机、复位可靠（复位芯片 U5 要贴，见引脚分配第 6 节） |
| 4 | 点屏：彩条、帧率、闪烁、触摸 | 按屏打样文件的验收项 |
| 5 | 前后摄切换、取景、拍照 | 画面正常，切换不花 |
| 6 | Air780E 高速 USB 拨号，4G 满功率发射时量供电跌落 | 拨号成功；供电跌落 ≤300 mV、不低于 3.3 V（规范第 4 节） |
| 7 | Wi-Fi、蓝牙连接和吞吐 | 能连，速率正常 |
| 8 | 喇叭、麦克风、TF 卡 4 线读写 | 正常 |
| 9 | 全部同时开 1 小时，记温度和电流 | 不重启、不掉线、不过热 |
| 10 | 休眠电流、按键唤醒 | 记数字，给续航估算 |

测试需要：可调电源、万用表、示波器（带宽 ≥100 MHz）、逻辑分析仪、4G 卡、TF 卡、电脑。

## 7. 现在就能做的事

1. 买 ESP32-S31-Korvo-1 开发板。
2. 向乐鑫代理询价：S31 模组（10 片样品和 1k 批量）、交期，要模组的 KiCad 封装和 3D 模型。
3. 向合宙确认 Air780E 的 USB 是否跑高速、样品采购。
4. 定连接器实际料号：摄像头 FPC 座、按键 FPC 座、Type-C、SIM 座、TF 卡座。
5. 找结构确认外壳两面限高和接口位置。
6. 我开始把原理图改成 S31（屏以外的部分先改）。
