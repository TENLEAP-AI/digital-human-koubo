# ESP32-S31 引脚分配（草案）

日期：2026-11-13。**已决定主控换成 ESP32-S31**，模组用 ESP32-S31-WROOM-1U-N16R16V（16 MB Flash、16 MB PSRAM、IPEX 天线座，18.0 × 20.5 × 3.2 mm）。
依据是乐鑫的 ESP32-S31 规格书和 WROOM-1U 规格书（都是预发布 v0.5）以及 ESP-IDF v6.1，见 [esp32-s31-evaluation.md](esp32-s31-evaluation.md)。
规格书定稿或开发板验证后可能还要调整。

## 1. 分配原则

1. **屏和摄像头用规格书里的专用高速引脚**。信号全部接在这些脚上时，ESP-IDF 的驱动自动走直连（IO MUX），速度最快。
2. **TF 卡用固定的 SDIO 引脚** GPIO20 ~ 25（ESP-IDF 的 SD 主机在 S31 上只能走这组脚）。
3. **按键和中断放在低功耗引脚** GPIO0 ~ 7 上，休眠时可以唤醒。
4. **启动配置脚** GPIO36、37 先不用（GPIO36 模组内部已上拉，见第 6 节）；GPIO60、61 只接对启动没影响的东西：GPIO61 接 BOOT 按键，GPIO60 接一个平时为高的中断。
5. 剩下的慢信号放一颗 XL9555 扩展芯片。

## 2. 主控引脚（串行 RGB 屏，NV3049F）

| GPIO | 用途 | 说明 |
|---|---|---|
| 0 | 扩展芯片中断 EXP_INT | 低功耗引脚，可唤醒 |
| 1 | 触摸中断 TP_INT | 低功耗引脚，点屏唤醒 |
| 2 ~ 7 | 按键 KEY1 ~ KEY6 | 低功耗引脚，按键唤醒；不再经过扩展芯片 |
| 8 ~ 15 | 屏数据 D0 ~ D7 | 专用高速脚（LCD_DATA0 ~ 7）。**8 根全接** |
| 16 / 17 | I²C SDA / SCL | 触摸、摄像头配置、扩展芯片、充电芯片共用 |
| 18 / 19 | 音频 BCLK / WS | |
| 20 ~ 23 | TF 卡 D0 ~ D3 | 固定 SDIO 脚，4 线 |
| 24 / 25 | TF 卡 CLK / CMD | 固定 SDIO 脚 |
| 33 / 34 | USB D− / D+（接 Type-C） | USB 串口 / JTAG，全速。下载、调试、日志都走这里 |
| 35 | 功放数据 | |
| 36 / 37 | **不用** | 启动配置脚：36 决定 Flash 电压，37 决定 JTAG 来源 |
| 38 | 麦克风数据 | |
| 39 | 背光调光 PWM | |
| 40 | 屏像素时钟 DOTCLK | 专用高速脚（LCD_PCLK） |
| 42 | TF 卡检测 SD_DET | |
| 43 / 44 / 45 | 屏 DE / HSYNC / VSYNC | 专用高速脚 |
| 46 ~ 53 | 摄像头数据 D0 ~ D7 | 专用高速脚（CAM_DATA0 ~ 7），前后摄共用，经总线开关切换 |
| 54 / 55 / 56 / 57 | 摄像头 PCLK / XCLK / VSYNC / HREF | 专用高速脚。这 4 个也是 JTAG 脚，调试改走 USB 口的 JTAG |
| 58 / 59 | 调试串口 RX / TX | UART0，独立，不再和屏共用 |
| 60 | 充电中断 CHG_INT | 启动配置脚，平时为高，只影响启动时的日志打印 |
| 61 | BOOT 按键 | 按住上电进下载模式 |
| USB_DP / USB_DM | Air780E 的 USB | **专用高速 USB（480 Mbps）**，不占 GPIO |

合计用 52 个，空 2 个（36、37 刻意不用）。

## 3. 屏用 QSPI（ST7102）时的不同

| GPIO | 用途 | 说明 |
|---|---|---|
| 10 | CS | SPI2 专用高速脚 |
| 12 | SCK | SPI2 专用高速脚，80 MHz 要用这组 |
| 11 / 13 / 14 / 9 | D0 / D1 / D2 / D3 | SPI2 专用高速脚 |
| 15 | TE | |
| 8、40、43、44、45 | 空出来 | |

其余不变。扩展芯片上的屏三线 SPI（3 路）也不需要了。

## 4. 扩展芯片（一颗 XL9555，地址 0x20）

| 方向 | 信号 |
|---|---|
| 输出 | LTE_PWR_EN、LTE_PWRKEY_EN、LTE_RESET_EN、CAM_PWR_EN、CAMF_PWDN、CAMR_PWDN、CAM_RST、CAM_SEL、PA_EN、LCD_RST、TP_RST、LCD_CS、LCD_SCL、LCD_SDA |
| 输入 | LTE_STATUS_N |
| 空 | 1 路（QSPI 屏时空 4 路） |

LCD_CS、LCD_SCL、LCD_SDA 是串行 RGB 屏的三线 SPI，只在开机发初始化命令，用扩展芯片模拟足够。

## 5. 和 S3 版原理图相比

| 改动 | 说明 |
|---|---|
| 主控模组 | ESP32-S3-WROOM-1U-N16R8 → **ESP32-S31-WROOM-1U-N16R16V**，符号和封装都要换 |
| USB | Type-C 的 D+ / D− 经 USBLC6 接 GPIO33 / 34；Air780E 的 USB 接专用高速口。**去掉 USB 切换芯片 FSUSB42（U6）和 USB_SEL** |
| 扩展芯片 | 两颗 → **一颗**。按键 6 路、触摸中断、充电中断、TF 卡检测改接主控 |
| 屏 | 数据线 5 根 → **8 根全接**；去掉 G0 ~ G2 的接地电阻；屏的 VSYNC / HSYNC 不再和串口共用，去掉相关串联电阻 |
| TF 卡 | 1 线 → **4 线**，固定接 GPIO20 ~ 25 |
| 调试串口 | 独立的 UART0（GPIO58 / 59），下载焊盘改到这里 |
| BOOT 按键 | GPIO0 → **GPIO61** |
| 摄像头主时钟 | 可以改由 GPIO55 输出，**去掉 24 MHz 有源晶振 Y1**。要在开发板上确认两颗摄像头用主控给的时钟正常 |
| 屏和触摸的接口 | 亚奇板对板公母座（另见打样文件） |

## 6. 读完官方资料后定下来的硬件要点（2026-11-14）

依据：《ESP32-S31 Hardware Design Guidelines》（2026-11-12 版，地址 docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s31/）、
芯片规格书第 2.5、5 章、WROOM-1U 规格书第 3、10、11 章、芯片勘误表、ESP32-S31-Korvo-1 开发板原理图。

| 项目 | 要求 | 出处 | 我们怎么做 |
|---|---|---|---|
| 3.3 V 供电 | 3.0 ~ 3.6 V，**电流不小于 600 mA**；电源入口加 ESD 管和至少 10 µF | 设计指南 1.3.2；规格书表 5-2 | 现在的 3.3 V 降压是 1 A，够。模组 3V3 脚旁放 10 µF + 0.1 µF |
| 使能脚 EN（CHIP_PU） | 不能悬空；3.3 V 稳定至少 1 ms 后才拉高；复位时低于 0.15 × VDD 至少 1 ms。推荐 RC：**10 kΩ + 1 µF** | 设计指南 1.3.3 | 照做，和 Korvo-1 一样 |
| 电池供电的复位 | 电源上电慢（比如电池充电）、频繁上下电时，**单靠 RC 不可靠，建议加电压监控芯片，门限约 3.0 V** | 设计指南 1.3.3 | 原理图里本来留了 U5（3.08 V 复位芯片，原来不贴）。**改成默认贴** |
| GPIO36 | 决定 Flash 电压，上电时必须为高 | 规格书表 4-4 | **模组内部已上拉**（WROOM-1U 规格书表 3-2 注 2），主板不用加。Korvo-1 还把它当屏数据线用，说明可以当普通脚用，但上电时外部不能把它拉低 |
| GPIO61（下载模式） | 建议外接上拉；**不能接大电容**，否则会误进下载模式 | 设计指南 1.3.9 | BOOT 按键接 GPIO61，加 10 kΩ 上拉，按键旁不放电容 |
| GPIO60 | 启动时只影响日志打印 | 设计指南 1.3.9 | 充电中断（开漏，平时为高），合适 |
| 深度休眠 | **只有 GPIO0 ~ 7 能在深度休眠时工作** | 设计指南 1.3.11 | 按键、扩展芯片中断、触摸中断都在 GPIO0 ~ 7，符合 |
| 输入高电平门槛 | **≥ 0.75 × 3.3 V ≈ 2.5 V** | 规格书表 5-4 | 2.8 V 的器件（摄像头 IO、触摸）直接接可以；**1.8 V 的必须加电平转换**（比如 in-cell 触摸如果是 1.8 V） |
| TF 卡（SDIO 槽 0，GPIO20 ~ 25） | 芯片内部供电，**不用外接上拉**；每根线建议串电阻，CLK 预留对地电容；1 线模式时没用的脚也不能挪作他用 | 设计指南 1.3.13 | 4 线模式，6 根线各串一个电阻（先 0 ~ 22 Ω），CLK 留电容位 |
| Type-C 的 USB（GPIO33 = D−，GPIO34 = D+） | 靠近芯片预留串联电阻（22 / 33 Ω）和对地电容位（先不贴） | 设计指南 1.3.14 | 照做 |
| 高速 USB（模组焊盘 54 = DM，55 = DP） | 专用脚，接 Air780E | 设计指南 1.3.14 | 90 Ω 差分，按高速 USB 要求走线 |
| 屏和摄像头 | 要高速就用 IO MUX 定义的专用脚 | 设计指南 1.3.17 | 已按专用脚分配 |
| 勘误和安全公告 | 勘误表列了两条：1.8 V Flash 启动失败、ECDSA 签名校验问题（芯片版本 v0.0 受影响）。另有安全公告 AR2026-006：v0.0 芯片的 **ECDSA 方式安全启动可被绕过，没有软件修复** | 芯片勘误表、AR2026-006 | Flash 那条不影响（模组是 3.3 V）。**安全启动必须用 RSA 方式**，不能用 ECDSA；量产前问清新芯片版本 |

**模组封装（画 PCB 最要注意的一点）**：WROOM-1U 是 18.0 × 20.5 mm、64 个焊盘。除了四周一圈，**模组肚子底下还有一圈 20 个 0.4 × 0.8 mm 的小焊盘**（焊盘 42 ~ 61），
外加 9 个接地散热焊盘。屏数据线 GPIO8 ~ 15、摄像头 D2 ~ D7（GPIO48 ~ 53）、GPIO16 ~ 19、**高速 USB 的 DM / DP** 都在这圈小焊盘上，
只能在模组下面打过孔引到内层。过孔放在小焊盘和四周焊盘之间的空地上，**必须盖油**（模组底部贴着板子）。
封装按 WROOM-1U 规格书图 11-2（推荐焊盘）画，散热焊盘按图打孔。
