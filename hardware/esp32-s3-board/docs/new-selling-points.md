# 用乐鑫现成能力给 AI 拍学机加卖点

日期：2026-11-14。每一条都核对过 ESP32-S31 支不支持（出处：ESP-IDF v6.1 的 S31 功能清单 `soc_caps.h`、ESP-DL 模型库、ESP-SR、esp-iot-solution 的组件说明）。
"性能待验证"的要在 Korvo-1 上实测。

## 1. 不用改硬件、价值高的（建议做）

| 卖点 | 小朋友 / 家长看到的 | 用乐鑫的什么 | S31 |
|---|---|---|---|
| **护眼提醒** | 脸离屏幕太近、看太久，屏幕提醒并自动变暗 | ESP-DL 人脸检测（用脸的大小估距离） | 支持，前摄就能做 |
| **认脸切换孩子** | 家里两个孩子，拿起来自动切到自己的学习记录 | ESP-DL 人脸识别 | 支持 |
| **看图识物学英语（不联网也能用）** | 对着苹果、小狗、杯子拍一下，屏上出英文单词和发音 | ESP-DL 图像分类（1000 类）、物体检测（80 类） | 支持，离线、秒出结果 |
| **隔空手势翻页** | 手在镜头前一挥翻下一页、比 OK 确认，手脏也不用摸屏 | ESP-DL 手势识别（8 种以上） | 支持 |
| **英文唤醒词、离线语音命令** | 用英文叫醒（沉浸英语），没网时"拍照""下一题""大点声"照样能用 | ESP-SR WakeNet10（中英日法等多语言）、MultiNet（300 条） | 支持（乐鑫写的是初步支持） |
| **蓝牙耳机** | 戴耳机听英语、看视频，不吵家人 | S31 支持经典蓝牙（A2DP）和低功耗蓝牙音频 | 芯片支持，软件待验证 |
| **跟读慢放、趣味变声** | 英语慢速听、录自己的声音变成卡通声 | ESP-Audio-Effects（变速不变调、变调） | 支持 |
| **错题本** | 拍过的题自动裁剪存下来，按科目整理，家长在 App 里看 | 硬件 JPEG + PPA 裁剪旋转 + TF 卡 | 支持 |

## 2. 要现在就定硬件的

| 卖点 | 说明 | 硬件影响 |
|---|---|---|
| **网课摄像头、实物展台** | 用 Type-C 插电脑，拍学机变成电脑的摄像头和麦克风，上网课或把作业拍给老师看 | 乐鑫有 USB 摄像头（UVC）和 USB 声卡（UAC）组件，都支持 S31。**但它们要用 S31 的高速 USB 口，而这个口现在接的是 Air780E**。要做这个卖点，就得把 USB 切换芯片加回来，让高速口在 Air780E 和 Type-C 之间切换（Type-C 平时仍接全速口下载调试） |

**这一条要在改原理图之前决定**。加一颗切换芯片成本不高，但不加的话以后做不了。

## 3. 可以做，但要先验证效果或性能

| 卖点 | 用乐鑫的什么 | 问题 |
|---|---|---|
| 坐姿提醒（驼背、歪头） | ESP-DL 人体关键点模型（支持 S31） | 乐鑫在 S31 上测的 YOLO11n（640 输入）一次要 8.7 秒，关键点模型要降分辨率才能用，要实测 |
| 认声音（谁在说话） | ESP-DL 声纹识别（只支持 S31 和 P4） | 准确率待测 |
| 家长远程看作业、视频通话 | ESP-WebRTC（有 S31 库） | 要服务器；S31 没有硬件 H.264，画质有限 |
| 同学之间对讲、比赛答题 | ESP-NOW（Wi-Fi 自带的点对点通信，不用路由器） | S31 上待验证 |
| 人坐过来屏幕自动亮（不开摄像头） | Wi-Fi 信号感知 CSI（S31 芯片支持） | 乐鑫的感知例程还没列 S31，效果受路由器影响 |

## 4. 不建议

- **端侧文字识别**：乐鑫的 OCR 模型只支持 P4，S31 上做不了，交给云端大模型。
- **触摸感应按键**：S31 的触摸通道在屏数据线用的那几个脚上，冲突。

## 5. 建议的优先级

1. 第一批（和拍题讲解一起做）：护眼提醒、看图识物学英语、离线语音命令、错题本。
2. 第二批：认脸切换孩子、隔空手势、蓝牙耳机、跟读慢放。
3. 先验证：坐姿提醒、远程看作业。
4. **马上要定**：要不要网课摄像头功能（决定加不加 USB 切换芯片）。
